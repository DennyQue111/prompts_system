# Content Formats

This skill is the entry point for deciding what kind of video project the user wants to make. It identifies the best-fitting project format and applies that format's requirements before creative development begins.

## Workflow

1. Read [`formats.md`](formats.md) and select the closest defined format using the user's brief.
2. If no format fits, clarify the intended project type when necessary; otherwise treat it as a new provisional category and record assumptions.
3. Carry the selected format's constraints into [`../screenplay-development/SKILL.md`](../screenplay-development/SKILL.md).
4. When the user requests shot planning, carry the approved script and format constraints into [`../shot-planning/SKILL.md`](../shot-planning/SKILL.md).
5. Continue to prompt execution only when the user requests production.

Keep format definitions and their detailed requirements in `formats.md`, not in this entry skill.
