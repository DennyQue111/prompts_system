# 复生协议 — 落地案例参考

《复生协议》是通用 project-structure skill 的**第一个完整落地案例**。本文件记录该项目的实际目录、命名细节、关键文件和踩坑历史，供新项目对照参考。

> 权威结构 + 进度以 `projects/复生协议/PROJECT.md` 为准；完整文件树见 `复生协议_full-tree.md`。

---

## 项目速览

- **类型**：AI 短片（约 4-5 分钟）
- **工具链**：Gemini 2.5 Flash（定型）+ ComfyUI（本地）+ GPT / Jimeng / MJ / Seedance
- **视觉风格**：v001 GANTZ:O 3D CG → v002（当前）Polished 2D anime key visual（见 `style_profile.md`）
