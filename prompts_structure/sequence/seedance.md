# Sequence · 视频生成镜头序列

## 是什么

Sequence 是**视频模型直出的镜头描述序列**。它的职责是告诉视频模型（即梦、Seedance 等）每一个镜头应该怎么动、怎么演、什么节奏。

Sequence 绑定你给的参考图，每次生成前先描述参考图结构，再逐镜写提示词。

---

## 核心原则

1. **参考图管视觉，文字管物理+摄影机。** 风格、色调、材质、渲染方式——参考图已经锁死了。文字不描述任何风格，只描述运动、力学、光线变化、镜头行为。全片设定中的「影像风格」仅用于 t2v 或无参考图时，i2v 模式下跳过。
2. **运镜是灵魂。** 视频区别于静帧的本质是"怎么动"——固定、缓推、横摇、手持跟拍、升降。每一个镜头都要明确选择。
3. **焦距影响空间感。** 35mm 的空间关系跟 85mm 完全不同——广角拉伸纵深、长焦压缩平面。焦距是独立于运镜的一级字段。
4. **动作描述靠物理，不靠形容词。** 告诉模型质量如何分布、力从哪来、材质如何响应、肢体如何恢复——不是"激烈打斗"。
5. **有人就写情绪。** 画面中能看清人物时，加情绪关键词帮助模型理解表演调性；无人省略整行。
6. **光影变化单独写。** 光线从头到尾不变就写"持续不变"；有变化就描述。
7. **参考图说清用途就不再重复——但当视频模型无法自动匹配合成图标签时，需在逐镜建立对应关系。** 前面写清楚每张图管什么后，画面内容直接描述画面本身。但如果生成结果与参考图完全无关，说明模型未能建立"镜头 ↔ 参考图区域"的对应关系，此时需在逐镜画面内容开头用括号标注对应区域（如"（对应合成图 CUT 1 区域）"），或在参考图描述中将每个区域单独列出并命名。
8. **Camera is a character.** 摄影机有动机、有逻辑、有跨镜演进。所有镜头写完后，必须附加摄影机运动总览表+摄影动机陈述。

## 输入结构

参考图描述块，用 `@image` 格式。每张图一行说清：是什么 + 管什么 + 不管什么。不需要独立的关联表格或边界段落。

```
## 参考图

@image [文件名.扩展名] — [名称]概念设计图——[管什么]。仅用于[边界范围]，不用于[边界外]。

@image [文件名.扩展名] — [名称]概念设计图——[管什么]。仅用于[边界范围]，不用于[边界外]。

@image [文件名.扩展名] — keyFrames 合成图——[几个镜头]的关键帧拼接。用于参考机位构图和光影色调。[如有风格偏差以第一张概念图为准]。
```

**关于 keyFrames 合成图：**
- Gemini 生成的 keyFrames 图上自带镜头号标签（如 CAD_0010），视频模型理论上能识别
- **不需要在 prompt 里描述每个镜头在合成图中的格子位置**——让模型自己按镜头号匹配
- ⚠️ **但实践中视频模型（如 Seedance/即梦）可能无法可靠识别合成图上的镜头标签**，导致生成结果与参考图完全无关。此时应采取以下补救措施：
  1. **在参考图描述中分区域命名**：将合成图的每个区域单独列出（如"区域A：角色参考"、"区域B：场景参考"、"区域C/CUT 1：CAD_0050 车内视角"）
  2. **在逐镜画面内容中标注对应关系**：每个镜头的画面内容开头用括号注明对应区域（如"（对应合成图区域C/CUT 1）"），然后正常描述画面
  3. **或拆分为多张参考图上传**：角色、场景、每个镜头各一张图，避免一张图信息过载
- 合成图的拼接方式由用户按时长需求决定（不固定），Sky 不预判排列方式

> **完整示例见 `examples.md`**。

## 全片设定

如果多个镜头共享相同的视觉母版、物理规则或全局禁令，在此集中描述一次——逐镜字段不再重复。不需要就跳过对应区块。

```
## 全片设定

### 全片影像风格（⚠️ i2v 模式下跳过此段，t2v / 无参考图时填写）
[适用于所有镜头的视觉母版。以下五项至少覆盖前三项（主导维度），不全则后两项标 — ：
- 基调色：（冷/暖/中性，饱和度高低）
- 光比：（高光比戏剧 / 低光比柔和）
- 光硬度/光型：（硬光单源 / 柔光漫射 / 背光剪影等）
- 逻辑光元类型：（光从哪来、为什么是这个颜色。同一场景所有镜头必须保持一致）
- 画面元素质感：（金属/玻璃/皮肤/布料/湿润表面等的主导材质]
⚠️ 逻辑光元类型对连续镜头尤其关键——同一场景内，shot 1 的路灯做主光，shot 2 就不能突然变成月光。]

### 灯光系统（必填——无论 t2v 还是 i2v）
[场景级灯光设计，所有镜头共享。至少覆盖以下五项：
- 主导色温：（具体 K 值，如 6000K 正午日光 / 3200K 暖钨丝灯）
- 主光方向与高度：（光源在摄影机哪一侧、多高、以什么角度穿过场景）
- 环境补光：（暗部的填充光——冷蓝绿环境反射 / 暖地反射 / 无明显补光则写"高反差，阴影深陷"）
- 特殊光效：（体积光光束 / 斑驳穿叶光 / 逆光剪影 / 粒子光尘 / 无则写 —）
- 光影变化规则：（同一光源穿透不同高度/密度的介质后如何变化，如"角色穿过冠层时交替进入光束与阴影，太阳本身不跳位"）]

### 物理规则（有角色/物体交互时必填，纯静态风景可跳过）
[场景内所有物体和角色的物理行为规则。至少覆盖：
- 质量关系：（角色间重量比、物体相对于角色的重量感，如"狼质量约为狐的1.3倍"）
- 落地与接触：（落地压缩深度、振起的碎屑类型和数量、着地姿势差异）
- 材质响应：（甲片受击滞后与归位、枝条受力弯曲后回弹、布料随速度飘动幅度）
- 次级运动：（毛皮/鬃毛/胡须/袍袖/腰带/尾巴对速度与气流的持续响应；明确哪些是配重体哪些是装饰）
- 空气与碎屑：（尘土/水珠/叶片/苔藓因接触或运动而剥落和飘散的行为）]

### 表演要点（有角色时必填）
[每个主要角色的行动哲学——不是情绪，是动作模式。每个角色一段：
- [角色名]： [行动逻辑 + 标志性动作模式 + 发力特征 + 表情范围]
示例："狼战士： 受控的蛮力。肩部始终前扣，口微张，双目锁定对手。每记攻击自沉髋发力，携带惯量并需可见恢复步。痛感与疲惫表现为血污毛皮、粗喘、前臂微颤、獠牙愈发暴露，绝不作夸张卡通式表演。"]

### 全片负面约束（可选）
[适用所有镜头的全局禁令——不需要在每个镜的负面约束里重复写]
```

> 全片已写过的约束，逐镜 `负面约束` 字段没有额外禁令就省略整行。

## 镜头模板

每个镜头用以下字段：

```markdown
### {shot_id} · {中文简述} · {时长范围}

- **画面内容**：[画面里有什么——谁、在哪、在做什么。纯物理描述，不写风格词，不写「基于 Image X」]
- **焦距**：[具体焦距 mm，如 35mm / 50mm / 85mm；或焦段如 24–35mm。写变化路径如有变焦]
- **运镜**：[固定 / 缓推 / 横摇 / 手持跟拍 / 升降 / 拉远 / 环绕 / 甩镜 / 变焦推；可组合如"低位手持跟拍 + 短后拉"]
- **动作**：[镜头内发生了什么事——物理描述，含质量感、力的来源与传递、材质响应、肢体恢复。武戏/动作戏按五段弧写]
- **视觉母题**：[（可选）一句抽象视觉锚点，如"暗色矛线切分画面"。动作戏建议写，静态镜头可省略整行]
- **情绪**：[有人物时写调性关键词，如"温柔克制"、"压抑恐惧"；无人省略整行]
- **光影变化**：[从头到尾不变 → "持续不变"；有变化 → 具体描述变化内容和时机]
- **衔接**：[切 / 叠化 / 淡入淡出 / 闪白 / 最后一个镜省略整行]
- **负面约束**：[（可选）本镜需要规避的错误，如"禁止镜头乱晃"、"禁止出现第二个人"]
```

### 字段约束

| 字段 | 必填 | 写法 |
|------|------|------|
| **画面内容** | ✅ | 纯物理描述，禁止风格词（anime、cel shaded、illustration 等） |
| **焦距** | ✅ | 具体 mm 数或有意义的焦段范围 |
| **运镜** | ✅ | 从选项列表中选，可组合 |
| **动作** | ✅ | 物理描述 + 节奏词；武戏/动作戏按五段弧写 |
| **视觉母题** | 看情况 | 动作戏建议写；静态镜头省略整行 |
| **情绪** | 看情况 | 有人物就写，无人省略整行 |
| **光影变化** | ✅ | "持续不变" 或具体写 |
| **衔接** | 看情况 | 最后一个镜省略整行 |
| **负面约束** | 看情况 | 有需要规避的点就写，没有省略整行 |

### 动作描述：五段弧（武戏/动作戏专用）

**仅当镜头涉及打斗、格斗、剧烈肢体动作时使用。** 文戏/静态镜头沿用原来的自由描述方式。

按真实动作逻辑描述五段：**预备 → 发力 → 峰值 → 回收 → 恢复**。

每个阶段加入物理细节：质量如何转移、哪个关节驱动、材质如何响应、惯量如何处理。

```
动作：她身体下潜闪避——重心压到前脚掌，髋部带动肩膀转出，脚掌碾碎湿落叶（预备→发力），
拳套短暂逼近镜头形成压迫感，拳风带起松散毛发（峰值），
拳打出后防守手立即回位，前臂微颤显示力量残留（回收），
快速起身+横移两步回到 guard stance，胸廓随呼吸起伏（恢复）。
整体爆发力强，节奏由缓到急再回收。
```

> 五段弧的核心是"动作有始有终"——打完要收、发力后要恢复。不要让动作悬浮在半空或无缝无限循环。物理细节（质量感、材质响应、力量传递路径）比形容词更能让模型理解运动。

### 焦距选项

焦距直接影响空间压缩感和画面张力。选择时考虑：

```
24mm–35mm → 广角：拉伸纵深，适合动作跟拍、空间展示、环境沉浸
50mm → 标准：接近人眼，适合对话、中性观察
85mm+ → 长焦：压缩空间，适合特写、极端情绪、攻击性逼近
变焦 → 如 50mm→35mm：镜头内焦距变化，伴随空间感转变
```

### 运镜选项

```
固定 → 机位不动，画面静止
缓推 → 画面缓慢向前推进，增强沉浸感
横摇 → 水平方向旋转，展示环境或跟随移动
手持跟拍 → 模拟手持摄影机，轻微抖动，纪实感
升降 → 垂直方向移动，改变视角高度
拉远 → 画面向后拉，从主体退到更大场景
环绕 → 围绕主体旋转，展示空间关系
甩镜 → 快速从一个主体甩到另一个
变焦推 → 焦段变化而非机位移动，压缩空间感
```

### 衔接选项

```
切 → 硬切，最常用
叠化 → 两镜重叠渐隐，过渡自然或暗示时间流逝
淡入淡出 → 黑场过渡，段落感强
闪白 → 强光瞬间覆盖画面，冲击/记忆/转换
省略整行 → 最后一个镜头不写衔接
```

## 摄影机运动总览

所有镜头写完后，附加以下两段：

### 摄影机运动逻辑表

| 镜头 | 焦距 | 运动 |
|------|------|------|
| 1 | XXmm | [运动描述] |
| 2 | XXmm | [运动描述] |
| ... | ... | ... |

### 摄影动机

[1–3 句解释整场运镜设计的内在逻辑。不是描述"做了什么"，而是解释"为什么这样做"。

示例："前三镜确立'蛮力 vs 灵动'对比；第四长镜纵向拓展决斗空间，令观众与格斗者同游；镜头5在空战时间变速后重置地理与重量感；镜头6抽去运动，使未解敌意成为最终重击。"]

## 使用时

1. 让对方**先发参考图，并说明每张图是什么**
2. Sky 生成时，**第一部分永远是参考图描述**（`@image` 格式，边界直接内联）
3. 然后逐镜填写模板——画面内容直接描述画面本身，不引用参考图编号（但如果生成结果与参考图无关，需在画面内容开头标注对应区域）
4. keyFrames 合成图上有镜头号标签，理论上不需要描述格子位置——但如果视频模型未能识别，需补充分区域描述
5. 逐镜写完后，**追加摄影机运动逻辑表 + 摄影动机**
6. 如果对方没说明某个字段需要的信息（如情绪、运镜倾向），主动问——别猜

> **完整示例见 `examples.md`**。
