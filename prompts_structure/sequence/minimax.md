# Sequence · MiniMax H3 视频生成镜头序列

## 是什么

Sequence (MiniMax H3) 是专为 MiniMax H3 模型设计的**时间段轴视频提示词序列**。与 Seedance/即梦的镜头单元结构不同，H3 以无缺口的时间段（0—15秒）为脊柱组织叙事，一段成品提示词直接对应一条完整的 H3 视频输出。

H3 的核心能力差异：**原生立体声生成**、**15秒连续时间轴**、**全正向描述**（不写 negative prompt）、**内联图片引用**、**严格标点语法**。

---

## 核心原则

1. **参考图管视觉，文字管物理+摄影机+声音。** 图片锁定人物身份、服装、材质、场景与色彩；文字只描述运动、力学、镜头行为、时间节奏与声音。i2v 模式下不写视觉风格词。
2. **时间段是脊柱。** 0—15秒无缺口覆盖，每个时间段写清画面内容、动作、镜位。连续不等于一镜到底——允许硬切、匹配剪辑、遮挡切换和尺度跳切，连续感来自人物身份、空间轴线、动作余势、核心道具、运动方向、色彩母题或声音桥。
3. **全正向描述。** 所有约束转化为正向的人物锁定、动作因果、摄影规则与结果定义，就地表达。不写 negative prompt，不写"禁止X"——写"X保持不变"。
4. **运镜是灵魂。** 每个时间段明确摄影机行为——固定、缓推、横摇、手持跟拍、升降、拉远、环绕、甩镜、变焦推。可组合。
5. **焦距影响空间感。** 35mm 拉伸纵深、85mm 压缩平面。焦距独立于运镜，是空间感的一级参数。
6. **动作描述靠物理，不靠形容词。** 质量如何分布、力从哪来、材质如何响应、肢体如何恢复。武戏按因果链写，不堆叠装饰动作。
7. **有人就写情绪。** 画面中能看清人物时写调性关键词；无人省略。
8. **光影变化单独写。** 不变写"持续不变"；有变化具体描述时机与内容。
9. **首帧即戏。** 每个时间段的第一帧锁定清晰、内容确定的画面——角色已在镜头中，动作已在发生。不写"空镜推进→角色入画"。
10. **声音是一等公民。** H3 生成原生立体声，声音设计独立成段——环境声、动作声、对白（含语言、声音质感、口型同步）、音乐、高潮落点。
11. **Camera is a character.** 摄影机有动机、有逻辑、有跨段演进。所有时间段写完后，附加摄影机运动总览表+摄影动机陈述。
12. **前景物件空间锚定（正向版）。** 画面中所有可被交互的前景物件在画面内容中明确声明不变性——"X位置与形态固定不变，始终保持为X"。跨段时间锚点在全片设定中集中声明一次。

## 输入结构

### 图片内联引用

先统计本次与提示词一起提交给 H3 的全部图片，按提交顺序编号为图片1、图片2、图片3。识别每张图片承担的角色、主体、场景、动作、构图、风格、装备或九宫格时序功能。

图片引用直接跟在对应对象名称后，统一使用全角括号：

```
白色机械战士（@图片1）
异形怪物（@图片2）
末日废墟世界（@图片3）
九宫格故事板（@图片1）
```

**规则：**
- 开篇的固定人物、主体与场景锁定段为每张图片建立明确绑定
- 后续每个时间段第一次出现相关对象时，延续相同内联引用
- 相同图片可在不同时间段重复引用，编号与对象绑定始终一致
- 一张图片包含多个主体时，分别为对象标注同一编号：`主角（@图片1）与同伴（@图片1）`
- 无图片时，正文直接从"生成一段15秒……"开始，正常描述主体

### 参考图绑定格式

```
## 人物与场景锁定

主体名称（@图片1）— 锁定该图片覆盖范围内的全部视觉身份：面部特征、发型、体型、服装款式、装备、材质与色彩。后续时间段中该主体出现时延续（@图片1）引用。

场景名称（@图片2）— 锁定环境布局、建筑结构、光源位置、色温基调与地面材质。后续时间段中该场景出现时延续（@图片2）引用。

九宫格故事板（@图片3）— 按从左到右、从上到下对应1—9镜或1—9状态。各时间段第一次引用其中状态时延续（@图片3）。
```

## 流程选择

H3 支持三种生产流程，每种有独立的生成机制。首次交互时先确定流程，再生成提示词。

### 流程1：文戏模式

**核心目标**：15秒承载一次清楚的关系变化——识破、承认、拒绝、原谅、背叛、离开、决定或失去。

**生成机制**：
1. 选择一个能被摄影机看懂的核心证据或道具，让它触发关系变化
2. 用5—8个时间段完成：建立关系与空间→证据出现→对方回应→主角消化→决定→行为结果→情绪余波
3. 切镜由新信息、说话权变化、视线目标变化、道具状态变化、人物距离变化或行动决定触发，不按每句台词机械正反打
4. 中近景或特写只保留2—3个协同的表演信号——目光停顿、呼吸变化、未完成的手部动作、身体重心变化。微表情前后连续，不写抽象情绪词
5. 对白简短自然，写清说话人、原文台词、使用语言、声音质感和口型同步
6. 结尾保留0.5—1.2秒呈现行为后果或表情余波

### 流程2：武戏模式

**核心目标**：高速但可读的连续攻防。每个有效动作必须改变距离、姿态、控制权、环境或下一招路径。

**默认节奏预算**：
- 开场起势：不超过0.5秒
- 有效动作：15秒内至少14—20个（攻击、闪避、格挡、借力、受击、追击、环境互动、反杀）
- 单个1.5—2.5秒动作段：通常含3—6个互相衔接的有效动作
- 慢动作：0—2次，总时长不超过0.6秒，只发生在真正接触帧
- 结尾定格：不超过0.3秒

**生成机制**：
1. 先锁定双方轮廓、尺寸、装备、能力边界、惯用手和空间位置
2. 设计完整战斗因果链：先手试探→第一次交换→对手升级→环境变化→主角受困→脱困反制→终结动作→结果落地
3. 上一招未完全收回时下一招已启动；格挡后的受力直接成为翻越、旋转、位移或反斩的动力
4. 每次攻击写清起手方向、目标、接触位置、受力反应和下一动作来源
5. 环境互动必须改变战斗局面，不是背景特效
6. 每组连招保持一个主要运动方向，只有人物真实换向、借墙反弹或重力改变时才改变摄影轴线
7. 终结动作包含命中、对手物理反应、主角卸力和明确结果

### 流程3：九宫格模式

**核心目标**：九个清晰可辨的关键画面，展示九个镜头、九个动作峰值或同一主体的九个演化状态。

**阶段A：生成九宫格**：
1. 从故事或图片中提取稳定主体和15秒视觉发展线
2. 拆成从左到右、从上到下的1—9格，每格承担不同任务
3. 九格覆盖：建立→触发→升级→第一次变化→中段状态→第二次升级→高潮形成→接近完成→最终画面
4. 生成16:9、2048×1152的3×3故事板，九个等大宽银幕画格，细整洁中性分隔线
5. 同一人物的身份、服装、装备、材质和关键配色贯穿九格；镜位、景别、姿态和动作明显变化

**阶段B：依据实际成图生成H3提示词**：
1. 先观察实际九宫格输出，逐格记录实际画面中的主体姿态、镜位、道具、空间状态、颜色和可见差异
2. 开篇将实际成图写为`九宫格故事板（@图片N）`，说明对应关系
3. 为九格分配无缺口的0—15秒时间段，所有九格必须在视频中出现，中间格不得被形变过程吞掉
4. 每格写"进入方式、画面中的主动作、离开方式"，前后格通过动作方向、形状、颜色、道具、遮挡或声音关联
5. 以实际九宫格为准，不沿用生成前已偏差的旧分镜

## 全片设定

如果多个时间段共享相同的物理规则、灯光系统或表演要点，在此集中描述一次——逐段不再重复。不需要就跳过对应区块。

```
## 全片设定

### 全片影像风格（⚠️ i2v 模式下跳过此段，t2v / 无参考图时填写）
[适用于所有时间段的视觉母版。以下五项至少覆盖前三项：
- 基调色：（冷/暖/中性，饱和度高低）
- 光比：（高光比戏剧 / 低光比柔和）
- 光硬度/光型：（硬光单源 / 柔光漫射 / 背光剪影等）
- 逻辑光元类型：（光从哪来、为什么是这个颜色。同一场景所有时间段必须保持一致）
- 画面元素质感：（金属/玻璃/皮肤/布料/湿润表面等的主导材质）]

### 灯光系统（必填——无论 t2v 还是 i2v）
[场景级灯光设计，所有时间段共享。至少覆盖以下五项：
- 主导色温：（具体 K 值）
- 主光方向与高度：（光源位置与角度）
- 环境补光：（暗部填充光类型）
- 特殊光效：（体积光 / 粒子光尘 / 无则写 —）
- 光影变化规则：（光源穿透不同介质后如何变化）]

### 物理规则（有角色/物体交互时必填）
[场景内所有物体和角色的物理行为规则：
- 质量关系：（角色间重量比、物体相对角色的重量感）
- 落地与接触：（落地压缩深度、碎屑类型和数量、着地姿势差异）
- 材质响应：（甲片受击滞后与归位、布料随速度飘动幅度）
- 次级运动：（毛发/袍袖/腰带对速度与气流的持续响应）
- 空气与碎屑：（尘土/水珠/叶片因接触或运动而剥落和飘散的行为）]

### 表演要点（有角色时必填）
[每个主要角色的行动哲学——不是情绪，是动作模式：
- [角色名]：[行动逻辑 + 标志性动作模式 + 发力特征 + 表情范围]]

### 格式模式
- **拍摄方式**：[single continuous take / multi-shot sequence with hard cuts / controlled multi-shot with dissolves]
- **时间模式**：[real-time / slow motion ×0.5 / speed ramp：normal → slow → normal / —]
- **画幅**：[16:9 / 21:9 / 4:3 / 1:1]

### 场景空间一致性（有可交互前景物件时必填）
[同一场景内所有时间段共享的空间锚点。声明格式（全正向）：
- **[物件名称]**：位于[空间位置描述]，[尺寸/形态描述]。所有时间段中位置与形态固定不变，始终保持为[物件名称]。
- **[物件A]与[物件B]的距离**：约[量化距离]——[可触及/需步行/远景虚化]。
如果某物件仅在部分时间段可见，注明参见时间段号。]
```

> 全片已写过的设定，逐段时间线不再重复。

## 首帧占用规则

视频模型的前 1—2 秒是"预热期"——如果不明确声明，模型倾向用模糊空镜、缓慢 fade-in 或无人物环境扫描填充。

### 首帧声明格式

在时间段的第一句锁定第一帧内容：

```
✅ "0—3秒：义肢少年（@图片1）已站在巷道中段，右臂铜色义肢垂在身侧，正沿巷道向前行走。"
❌ "0—3秒：我们看到一条雨夜巷道。然后少年出现并开始行走。"
```

### 首帧规则

| 规则 | 说明 |
|------|------|
| 角色在第一帧可见 | 不写"空镜推进→角色入画"。如果时间段要拍角色，第一帧就有角色 |
| 动作在第一帧已在发生 | 不写"静止→开始动"。角色在第一帧已处于动作进行态 |
| 建立镜头用场景物件 | 如需建立镜头，用场景中已有固定物件（路灯、建筑剪影），不用空黑画面 |
| ≤3秒的时间段绝对禁止空镜建立 | 短时间段没有时间浪费——第一帧就是戏 |

## 时间段模板

每个时间段用以下字段：

```markdown
### {时间段范围} · {中文简述}

- **画面内容**：[画面里有什么——谁、在哪、在做什么。纯物理描述，不写风格词。首句锁定第一帧内容，遵守首帧占用规则。人物/主体/场景首次出现时使用内联图片引用（@图片N）。]
- **焦距**：[具体焦距 mm，如 35mm / 50mm / 85mm；或焦段如 24–35mm。写变化路径如有变焦]
- **运镜**：[固定 / 缓推 / 横摇 / 手持跟拍 / 升降 / 拉远 / 环绕 / 甩镜 / 变焦推；可组合]
- **动作**：[镜头内发生了什么事——物理描述，含质量感、力的来源与传递、材质响应、肢体恢复。武戏按因果链写：A—B—C—D]
- **情绪**：[有人物时写调性关键词；无人省略整行]
- **光影变化**：["持续不变" 或具体描述变化内容和时机]
- **衔接**：[切 / 叠化 / 淡入淡出 / 闪白 / 最后一个时间段省略整行]
```

### 字段约束

| 字段 | 必填 | 写法 |
|------|------|------|
| **画面内容** | ✅ | 纯物理描述，禁止风格词；首句锁定第一帧；内联图片引用 |
| **焦距** | ✅ | 具体 mm 数或有意义的焦段范围 |
| **运镜** | ✅ | 从选项列表中选，可组合 |
| **动作** | ✅ | 物理描述 + 节奏词；武戏按因果链写 |
| **情绪** | 看情况 | 有人物就写，无人省略整行 |
| **光影变化** | ✅ | "持续不变" 或具体写 |
| **衔接** | 看情况 | 最后一个时间段省略整行 |

### 画面内容中的空间锚定（正向版）

视频模型在镜头运动时倾向于对画面内容逐帧"重新解释"——前景物件可能漂移、变形、被替换。空间锚定是对抗此倾向的核心手段。

**H3 版写法——三重正向声明：**

```
画面内容：……画面中央偏下位置，义肢少年（@图片1）站立于圆形工作台前。工作台为圆形树桩横截面，直径约80cm，位置与形态固定不变，始终保持为木质树桩工作台。工作台前方约60cm处有一只三足小木凳，高约20cm，位置与形态固定不变，始终保持为同一只木凳。画面下方偏右有一处小型地面火坑，位置与暖光色温固定不变。……
```

三重声明结构（全正向）：
1. **物件 + 空间位置描述 + 尺寸**（在哪、什么形态、多大）
2. **"位置与形态固定不变"**（硬锁定——正向表述）
3. **"始终保持为[物件名称]"**（防物件替换——正向表述）

> 如果已在`全片设定·场景空间一致性`中声明跨段时间锚点，逐段画面内容中不再重复声明——仅描述角色与其交互的动作。

### 动作描述：武戏因果链

武戏/动作戏按因果箭头链写——每个动作的受力直接成为下一动作的动力来源：

```
动作：她身体下潜闪避—重心压到前脚掌—髋部带动肩膀转出—脚掌碾碎湿落叶—拳套逼近镜头形成压迫—拳风带起松散毛发—防守手立即回位—前臂微颤显示力量残留—快速起身横移两步回到guard stance—胸廓随呼吸起伏。
整体爆发力强，节奏由缓到急再回收。
```

> 核心是"动作有始有终"——打完要收、发力后要恢复。物理细节（质量感、材质响应、力量传递路径）比形容词更能让模型理解运动。

### 焦距选项

```
24mm–35mm → 广角：拉伸纵深，适合动作跟拍、空间展示、环境沉浸
50mm → 标准：接近人眼，适合对话、中性观察
85mm+ → 长焦：压缩空间，适合特写、极端情绪、攻击性逼近
变焦 → 如 50mm→35mm：镜头内焦距变化，伴随空间感转变
```

### 运镜选项

```
固定 → 机位不动，画面静止
缓推 → 画面缓慢向前推进，增强沉浸感
横摇 → 水平方向旋转，展示环境或跟随移动
手持跟拍 → 模拟手持摄影机，轻微抖动，纪实感
升降 → 垂直方向移动，改变视角高度
拉远 → 画面向后拉，从主体退到更大场景
环绕 → 围绕主体旋转，展示空间关系
甩镜 → 快速从一个主体甩到另一个
变焦推 → 焦段变化而非机位移动，压缩空间感
```

### 衔接选项

```
切 → 硬切，最常用
叠化 → 两镜重叠渐隐，过渡自然或暗示时间流逝
淡入淡出 → 黑场过渡，段落感强
闪白 → 强光瞬间覆盖画面，冲击/记忆/转换
省略整行 → 最后一个时间段不写衔接
```

## 声音设计

H3 生成原生立体声，声音设计是独立必填段落，放在时间线之后。

```
## 声音设计

- **环境声**：[持续背景音——雨声密度、风声方向、远处交通嗡鸣、电子设备运转声等]
- **动作声**：[关键动作的音效——金属碰撞质感、布料摩擦、脚步落地材质、水花飞溅大小等]
- **对白**：[说话人 + 原文台词（用双引号）+ 使用语言 + 声音质感 + 口型同步说明。无对白写 —]
- **音乐**：[有无配乐、乐器类型、节奏特征、高潮落点。无配乐写 —]
- **声音空间感**：[声源方位——左/右声道、远/近、移动轨迹。H3 立体声能力利用]
```

### 配乐规则

- **2D 动画风格场景默认无配乐**：音乐字段写 "—"
- **写实/电影感场景**：根据剧情需要决定
- 用户说"不要背景音乐"或"无配乐"时，音乐字段必须写 "—"
- 用户未提及配乐时：2D 动画→默认 —，其他风格→根据剧情判断

### 对白标点规则

双引号（中文""或英文""）**只**标记角色在成片中实际说出口的台词：

```
✅ 少年低声说："别回头。"
✅ 领头小孩喊道："又一个机械怪人，滚！"
❌ 动作链"女人观察后视镜—发现追兵"（动作链不用引号）
❌ "温柔克制"（情绪概念不用引号）
```

## 标点语法规则

| 标点 | 用途 | 示例 |
|------|------|------|
| 双引号 "" / "" | **只**用于角色实际说出口的台词 | 少年说："别回头。" |
| 破折号 — | 动作因果链连接 | 观察后视镜—发现追兵—移开男人手臂 |
| 冒号 ： | 段落标题 | 剪辑与动作：、视觉风格：、声音设计： |
| 顿号 、 | 并列项 | 目光停顿、呼吸变化、手部动作 |
| 分号 ； | 同句中的层次分隔 | 先看A；再看B |
| 逗号 ， | 自然句内停顿 | — |
| 全角括号 （） | 图片内联引用 | 白色机械战士（@图片1） |

**禁止**：用双引号标记动作链、镜头名称、段落标题、情绪概念、画面文字或强调内容。

## 交付前自检

生成前逐项检查：

- [ ] 是否已确定文戏、武戏或九宫格流程
- [ ] 是否复用了用户已给出的故事或图片，没有要求重复发送
- [ ] 人物、服装、装备、主体和场景是否保持一致
- [ ] 时间段是否无缺口覆盖0—15秒
- [ ] 文戏是否只有一次清楚的关系变化，对白语言和口型是否明确
- [ ] 武戏是否达到动作密度，每次接触是否有受力和后续结果
- [ ] 九宫格是否九格全部不同，并依据实际成图撰写视频提示词
- [ ] 连续性是否来自可见锚点，而不是被错误强制成一镜到底
- [ ] 首帧是否锁定清晰内容（角色已在、动作已在发生）
- [ ] 前景可交互物件是否做了正向空间锚定声明
- [ ] 声音设计是否完整（环境声 / 动作声 / 对白 / 音乐 / 声音空间感）
- [ ] 双引号是否只出现在角色实际说出口的台词中
- [ ] 所有描述是否为全正向（无 negative prompt、无"禁止X"）
- [ ] 图片引用是否以内联形式紧跟对应对象，编号一致
- [ ] 输出是否为 H3 可直接复制的自然语言提示词

## 使用时

1. 让对方**先发参考图并说明每张图是什么**，或发故事/图片
2. **先确定流程**（文戏 / 武戏 / 九宫格），再生成
3. 第一部分永远是**人物与场景锁定段**（内联图片引用格式）
4. 然后写**全片设定**（灯光 / 物理 / 表演 / 空间一致性）
5. 逐段填写**0—15秒时间线**——首句锁定第一帧，遵守首帧占用规则
6. 追加**剪辑与动作**、**视觉风格**（i2v 下极简）、**声音设计**
7. 最后附加**摄影机运动总览表 + 摄影动机**
8. 如果对方没说明某个字段需要的信息（如情绪倾向、运镜偏好），主动问——别猜

## 与 Seedance 序列结构的关键差异

| 维度 | Seedance (sequence/seedance.md) | MiniMax H3 (本文件) |
|------|------|------|
| 组织方式 | 镜头单元（shot-based） | 时间段轴（time-segment-based） |
| 时长 | 变长（用户指定每镜） | 固定15秒 |
| 声音 | 无声音设计 | 独立声音设计段（环境/动作/对白/音乐/空间感） |
| 约束方式 | 负面约束（禁止X） | 全正向（X保持不变） |
| 图片引用 | @image 块式声明 | 主体（@图片N）内联引用 |
| 模式系统 | 无模式区分，五段弧可选 | 文戏 / 武戏 / 九宫格三流程 |
| 标点规则 | 无特定标点规则 | 严格标点语法（双引号只用于台词） |
| 输出格式 | 结构化 Markdown | 自然语言段落，可直接复制进 H3 |
| 首帧规则 | 有（镜头级） | 有（时间段级） |
| 空间锚定 | 三重声明（含"禁止变成X"） | 三重正向声明（"始终保持为X"） |
| 摄影动机 | 有 | 有 |
| 距离量化 | 有 | 有 |
