# Scene Adaptation · 场景级表演改写

## 是什么

当角色从 Master Profile 进入一个具体场景时，行为需要按场景条件改写——不是改角色是谁，而是改角色在这一场景中怎么行动。档案锁死角色 DNA，场景改写当下的策略和节奏。

## 场景改写 = 五支柱落实到行为

### 1. Objective（目标）

**一个主动词，对准另一个角色。**

目标必须是一个动词——"我想让他……"——不是状态、不是情绪、不是想法。

```
❌ "他感到绝望"
✅ "他想让她最后看他一眼"
```

目标可以被胜利、被挫败、被替换——但它必须在对戏中产生摩擦。

### 2. Obstacle & Stakes（障碍与赌注）

**失败有代价。代价必须被身体化。**

障碍不是"反派很强"，是"此刻阻止目标达成的具体事物"。赌注不是"世界毁灭"，是"如果失败，角色会失去什么他能感受到的东西"。

```
目标：让他承认他说谎了
障碍：他是我老板，周围全是同事
赌注：如果他不承认，我就得辞职——这是我最后一笔工资
```

代价要有身体痕迹——紧握的拳头、变白的指节、吞咽、下巴绷紧。

### 3. Tactics（策略）

**不断切换策略，一个动词一个拍子。**

场景不能从头到尾一个策略。每一个拍子换一个动词：请求 → 施压 → 嘲讽 → 退让 → 摊牌。换策略的瞬间必须有身体信号——停顿、姿势变换、距离调整、音调切换。

```
拍子 1：哄（语气轻、身体前倾、微笑）
拍子 2：试探性揭穿（语气变平、后靠、看别处）
拍子 3：直接质问（身体站直、声音压低、眼睛锁定）
```

### 4. Beats（拍子）

**2–4 个行为拍子，每个都有可见起点和终点。**

拍子不是"情绪段落"，是**一个可观察的行为脉冲**——一个完整的动作单元（目标→执行→结果→调整）。

```
✅ 拍子可观察的终点：
- 他开口请求 → 对方沉默 → 他换了策略（可见的行为变化）
- 她伸手碰他 → 他退开 → 她的手悬在半空，然后放下
```

### 5. Subtext（潜台词）

**身体在做一件事，嘴在说另一件。**

潜台词不靠形容词描述——靠身体和语言的**物理矛盾**来体现。

```
台词："没关系。"
身体：手指敲桌子，下巴收紧，眼睛不看对方。
→ 身体说"有关系"。
```

## 改写清单

为每个场景镜头，从 Master Profile 出发：

- [ ] 角色此刻的目标是什么（一个动词，对准谁）
- [ ] 障碍和赌注是什么（失败的代价有身体痕迹）
- [ ] 2–4 个拍子——每个拍子对应一个策略动词，策略切换有可见身体信号
- [ ] 台词和身体之间有张力吗（有潜台词比没有好）
- [ ] 反应在对方说完之前就已经开始了吗
- [ ] 状态有惯性——上一个拍子的身体痕迹延续到下一个拍子了吗

## 身体物理生命（每镜头检查）

以下六项是**行为的基础设施**，如果档案中定义了，场景中要落实：

| 维度 | 检查 |
|------|------|
| **重心** | 低/高/前倾/后仰——此刻处于什么姿势？这个姿势和角色此刻的权力/状态匹配吗？ |
| **速率** | 动作是快还是慢？速率变化了吗？人物紧张→动作会变快或完全冻结。 |
| **开放度** | 身体朝向对方还是背对？手臂交叉还是打开？空间在扩大还是收缩？ |
| **呼吸** | 胸式还是腹式？浅快还是深慢？呼吸改变是最早的情绪信号。 |
| **手头动作** | 有一件正在做但在某个时刻被打断的事吗？——被打断 = 最强表演标点。 |
| **空间距离** | 离对方多远？距离在变化吗？靠近是压力、退后是退缩、静止是僵持。 |

### 距离即权力（Proxemics）

| 距离变化 | 行为含义 |
|----------|----------|
| 靠近（入侵对方空间） | 施压、挑战、亲密尝试 |
| 退后 | 退缩、恐惧、放弃、被压服 |
| 不动但身体侧转 | 防御——不退但设屏障 |
| 站着看坐着的人 | 支配 |
| 坐在对方正在站着时 | 反常权力——弱势位置反压 |
| 停在门口 | 阈限时刻——决定尚未做出 |

## 群戏规则

镜头中有多个人物时：

- [ ] 每个有镜头的角色都有**独立目标**（不共享一个"集体情绪"）
- [ ] 反应**交错进行**——不是所有人同时转头的海浪式同步
- [ ] **强者静止，弱者躁动**——力量通过控制来表演，焦虑通过小动作来表演
- [ ] 最少一个角色在做和场景情绪相反的事（一个人悲伤，另一个在找钥匙）

## 输入输出

**输入**：Master Profile + 剧本场景（角色在此场景中做什么、说什么）

**输出**：场景级表演描述——可直接填入 Sequence/Shot 的「动作」和「情绪」字段。

**不是**：场景分析文字。改写的结果是直接可用的提示词片段，不是文学评论。
