# Acting Master Profile · 角色表演主档案

## 是什么

一份 **150–220 词的英文角色表演档案**，描述角色的全部可拍摄物理行为。它不描述角色"是什么样的人"，而是描述角色在摄影机前**如何存在**——身体如何占据空间、如何移动、如何处理沉默、紧张从哪里显现。

**核心原则**：档案中不准出现一个内部心理词（brave、sad、kind、angry、loyal）。所有描述必须是可观察的物理行为——身体的、声音的、空间的、节奏的。

## 模板

```text
Character acting as [NAME]. [Age/sex baseline], [build and physical description — body architecture, not costume]; [center of gravity and default posture]; [psychological engine — one sentence, the single driving impulse this character runs on]. Vocal profile: [register, tempo, rhythm, accent, a signature habit of speech — what changes when they get serious/scared/angry]. Key physical habits and tics: [2–4 observable physical behaviors with clear triggers — "does X when sizing up a situation" rather than "often does X"]. Eye life: [dominant quality of gaze — scanning vs fixed, blink speed and frequency, where attention lives, catchlights quality]. Walking style: [weight distribution, step length, tempo, what body parts lead, any asymmetry]. However, when [a specific triggering condition], [the single specific physical tell that betrays them — the mask cracks in a describable way]. [One sentence about what genuinely softens their default state — the one thing that makes them drop the armor, described physically].
```

## 逐段说明

### 1. 基本身份 + 身体架构

年龄、性别、体型——不是服装，是骨骼和肉。体型描述要有"职业痕迹"而非"健身房分类"。

```
Good: "heavy, thick-necked build gone soft at the middle, with a flat-nosed face and old scar tissue over both eyebrows"
Bad: "muscular athletic build"
```

### 2. 重心与默认姿态

身体如何占据空间。低重心 = 稳重/威胁/扎根。高重心 = 轻盈/警惕/漂泊。前倾 / 后仰 / 不对称。

```
Good: "sits and stands with a low, grounded center of gravity, weight always on the whole foot"
```

### 3. 心理引擎

一句话——推动这个角色所有行为的单一驱动力。不是性格描述，是行为引擎。

```
Good: "decades of waiting — for fares, for rounds, for trouble — have made patience his weapon"
Bad: "he is patient and wise"
```

### 4. 声线档案

音域（低/中/高）、速率、节奏、口音、标志性语言习惯、情绪变化时声线如何变——降得更低还是变尖？加速还是减速？

```
Good: "low, hoarse, unhurried baritone, short flat economical sentences, dropping to a slower, quieter register the more serious things get — he never speeds up"
```

即使镜头没有对白，声线档案也为呼吸、唇部运动、面部张力提供依据。

### 5. 身体习惯与小动作（2–4 个）

每个习惯必须有**明确触发条件**。不是"他经常摸鼻子"，而是"当他评估形势时会摸鼻子"。

三个典型触发类别：
- **评估/等待时**：评估对象、等待结果、消化信息
- **压力/谎言/冲突时**：防御性动作、自我安抚、攻击前兆
- **放松/真实时**：只在特定对象面前出现的习惯

```
Good: "rolls an old coin across his knuckles when sizing a situation up; a slow, audible nose-breath before he says no"
Bad: "often plays with a coin"
```

### 6. 眼部生命

目光质量——扫视还是凝视、眨眼速率与质量、注意力锚点在哪、catchlights 质感。

```
Good: "sleepy, hooded eyes with slow deliberate blinks and constant quiet scanning — mirrors, hands, exits — the gaze settling on a speaker a beat before his head turns; catchlights low but alive"
```

### 7. 走路风格

重心分布、步幅、速率、哪个身体部位先启动、有无不对称。

```
Good: "a heavy, rolling walk, short economical steps, shoulders level, hands loose and ready, never hurrying"
```

### 8. 破绽（However, when...）

**最关键的一条。** 没有一个真实的人物永远保持同一个面具。找到那个让面具裂开的特定触发条件，描述具体的、可观察的身体反应。

```
Good: "However, when someone raises a hand near him, the sleepy mask vanishes in a half-second: the chin drops, the hands rise halfway, the feet find their old stance — then he catches himself and folds it away, embarrassed."
```

### 9. 软化目标

什么东西能让这个角色摘下面具——描述为身体变化。

```
Good: "His face only truly softens for stray dogs, which he feeds from his coat pocket."
```

## 关键规则

1. **档案中不准出现一个内部心理词。** brave/sad/angry/kind/warm/cold → 全部替换为可观察的身体行为。
2. **每个习惯必须有触发条件。** "当他 X 的时候会做 Y"——不是"他经常做 Y"。
3. **身体 > 语言。** 当身体信号和台词冲突时，观众相信身体。档案必须定义身体信号。
4. **声线档案不因场景改变。** 这是角色的固定 DNA，逐镜不做任何修改——直接贴入音频字段。
5. **这份档案用于每个需要这个角色的镜头。** 同一角色在不同场景中，身体档案和行为模式不变，改变的是场景级的策略和拍子。
