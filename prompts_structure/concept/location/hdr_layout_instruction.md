# Location Concept — HDR 4-Panel Layout Instruction

## Layout Grid (16:9)

```
┌──────────────────┬──────────────────┐
│                  │                  │
│     左上: 正面    │     右上: 右侧    │
│     (0°)         │     (90°)        │
│                  │                  │
├──────────────────┼──────────────────┤
│                  │                  │
│     左下: 背面    │     右下: 左侧    │
│     (180°)       │     (270°)       │
│                  │                  │
└──────────────────┴──────────────────┘
```

4 个等分面板，2×2 网格。每个面板是从**同一站立位置**朝不同方向拍摄的广角环境照片，每转 90° 拍一张。4 张合在一起构成该位置的 360° 环境全貌。

## Panel Definitions

- **左上（正面 0°）**：场景的主视角方向。通常是对着故事主要行动发生的方向——角色走来的方向、对话发生的朝向、战斗展开的正面。这张是"主视觉"。

- **右上（右侧 90°）**：从正面右转 90° 看到的画面。展示主视角看不到的侧面空间——墙壁材质、侧面通道、光源位置、建筑侧面细节。

- **左下（背面 180°）**：从正面转 180° 看到的画面。展示角色背后发生什么——来路、背后的建筑入口、反方向的空间纵深。这张和正面一起构成场景的"进退关系"。

- **右下（左侧 270°）**：从正面左转 90°（或右转 270°）看到的画面。与右侧对称，展示另一侧的环境信息。

## Camera Specification

- **焦距**：28mm（全画幅等效）。广角但形变极轻微——28mm 是环境覆盖和形变控制的最佳平衡点。24mm 可用于狭窄空间但边缘形变增大；35mm 形变最小但视野不足。
- **机位高度**：人眼高度（约 1.6m），除非场景有特殊视角需求
- **格式**：每张照片为竖构图的 4:3 或横构图的 3:2，4 张拼入 16:9 画面

## Background & Dividers

4 张照片之间用细深色分隔线分开。面板标签（"正面 0°" / "右侧 90°" / "背面 180°" / "左侧 270°"）为小号清晰文字，置于每张照片下方。整体为一张 16:9 图像。

## Full Prompt Composition

```
[Layout instruction: 16:9 HDR 4-panel layout, 2×2 grid, equal panels, 28mm wide-angle, 90° rotation per panel] +
[Location identity: name + type + function tag + time + weather] +
[Panel 1 (左上/正面): 主视角方向的环境描述 — 建筑、光源、地面、纵深] +
[Panel 2 (右上/右侧): 右转90°的环境描述 — 侧面空间、墙壁材质、侧光源] +
[Panel 3 (左下/背面): 180°反转的环境描述 — 来路、背后空间、进退关系] +
[Panel 4 (右下/左侧): 左转90°的环境描述 — 另一侧环境信息] +
[Style suffix]
```

## Key Rules

1. **同一站立位置**：4 张照片必须从同一个点拍摄——只是旋转方向，不移动位置。这是 HDR 布局的核心约束。如果 4 张照片来自不同位置，空间关系会混乱。
2. **28mm 广角**：统一使用 28mm 焦距。广角够拍下更多环境内容，同时形变极轻微。不要用鱼眼或超广角（16mm 以下），边缘形变会干扰视频模型的场景理解。
3. **正面面板是主视觉**：左上面板（正面 0°）是场景的"主视觉"——光线、时间、氛围以此面板为基准，其他面板保持一致。
4. **4 张照片光线一致**：所有面板的光源方向是物理一致的——如果正面有霓虹灯从头顶照下，那么背面面板也应该能看到同一霓虹灯的背面光晕。光源是空间中的物理存在，不是每个面板独立打光。
5. **无人物**：场景概念图不含人物。用建筑元素（门、车、路灯、家具）作为比例参照。即梦等平台容易从参考图中带入人物，必须在 @image 声明中注明"不复制参考图中的人物"。
6. **面板标签清晰**：每个面板下方标注方向角度（"正面 0°" / "右侧 90°" / "背面 180°" / "左侧 270°"），便于后续视频提示词中用 @image 右上部分 的方式精确引用。

## 与 general_layout_instruction 的区别

| 维度 | general_layout_instruction | hdr_layout_instruction |
|------|---------------------------|----------------------|
| 面板数 | 6+ 个不同类型面板 | 4 个等分方向面板 |
| 面板类型 | 主视觉/反向角度/俯视/中景/细节/色板 | 4 个 90° 旋转的广角环境照 |
| 信息维度 | 设计文档（俯视图、色板、细节特写） | 摄影参考（站在场景里看到什么） |
| 视频模型友好度 | 中——俯视图和色板对视频模型用处不大 | 高——每个面板就是一个直接可用的镜头角度参考 |
| 引用方式 | 需要描述"对应合成图区域C" | 直接 @image 右上部分 |
| 适用场景 | 需要色板和俯视空间图的制作流程 | 需要快速为视频生成提供场景参考 |
