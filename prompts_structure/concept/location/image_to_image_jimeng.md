## Description

即梦（Jimeng）平台的 image-to-image **场景概念设计**提示词结构。与 frame 级 i2i 不同，此结构用于生成 **HDR 4 面板场景概念图**——一张 16:9 布局图，4 个等分面板分别从同一位置朝 4 个方向（正面/右侧/背面/左侧）拍摄的广角环境照，专为视频生成中的场景一致性锚定服务。

**核心理念：** 上传场景参考图（MJ 生成图、照片、其他 AI 生成图），在即梦生成一张 16:9 HDR 4 面板场景概念图。参考图提供风格 DNA（色调、笔触、氛围、光影逻辑），提示词负责定义场景的空间结构、建筑特征和环境动态。

**Layout 参考：** `hdr_layout_instruction.md`——16:9 HDR 4 面板布局（2×2 等分，4 个 90° 旋转广角环境照，28mm）。

**前置必读：** 撰写任何 prompt 前，请先阅读 [`meta/prompt-hygiene.md`](../../meta/prompt-hygiene.md) 中的八条横切规则与四问自检清单。

---

## 即梦 i2i 场景概念工作流

1. **上传参考图**（1–2张：场景参考图、风格参考等）
2. **选择参考模式**
   - **风格参考**：中低相似度（30–50%），提取色调/笔触/氛围/光影逻辑。**场景概念图最常用此模式。**
   - **构图参考**：中相似度（50–65%），锁定空间透视关系和景深结构。
   - **角色特征**：不适用于场景概念图。
3. **写中文提示词**（结构见下方，基于 hdr_layout_instruction）
   - ⚠️ **字数限制：即梦 prompt 输入框有 2000 字上限。** 场景概念表面板多、信息量大，必须按优先级取舍（见下方取舍原则）。
4. **调整反向提示词**（中文，5–8 个词）
5. **选择画风标签**（如「概念设计」「插画」「动漫」）辅助锚定

## 分析流程（精简版 5 步）

撰写提示词前，先对参考图做以下分析。分析过程不需要写进最终 prompt，但分析结果决定 prompt 内容。

### Step 1: 参考图观察

客观描述参考图中可见的内容——不发明、不美化。

| 类别 | 观察要点 |
|------|---------|
| **地理** | 地形类型（城市/乡村/山野/工业/虚空），地势起伏，自然与人造比例 |
| **空间布局** | 前景（近、细节多）→ 中景（主体区域）→ 背景（纵深、消失点）的三层结构 |
| **建筑** | 建筑风格、年代、材料、结构语言（粗野/有机/赛博朋克/民居/极简），高度范围，密度，状况 |
| **基础设施** | 道路、桥梁、电线、路灯、招牌、公共交通元素 |
| **时间天气** | 时间段，季节，天气（晴/雨/雾/雪/霾），天空状况 |
| **光源** | 每个可见光源：自然光（日/月方向）、人工光（路灯/霓虹/窗户/车灯）、环境光（天光/反射）。记录色温和扩散方式 |
| **氛围** | 光线和天气传达的情绪（在叙事语境之前）。颗粒物：雾/霾/雨/尘/烟/余烬 |
| **材质** | 主导表面材质：湿沥青、锈金属、光滑玻璃、粗糙混凝土等。每种材质如何与光互动 |
| **色彩分布** | 背景基色（%覆盖）+ 中景点缀色 + 前景细节色 |
| **生活痕迹** | 磨损、锈迹、碎片、涂鸦、废弃物——使用和时间流逝的痕迹 |
| **比例参照** | 什么提供尺寸参照：人物、车辆、门、路灯 |

**规则：** 如果元素被阴影、景深虚化、雾气遮挡，标注"不可见"——不要猜。

### Step 2: 风格分析

参考图的渲染美学是即梦需要近似的核心。拆解以下维度：

| 维度 | 要点 |
|------|------|
| **线条** | 有无明显轮廓线 / 线条粗细一致性 / 线条性格（机械精确/笔触感/速写/墨线） |
| **阴影** | 平涂赛璐璐 / 柔和渐变 / 硬阴影高对比 / 环境光遮蔽 / 阴影深度（浅/中/深黑） |
| **色彩** | 冷暖倾向 / 饱和度（高/低/选择性饱和）/ 色调感（青橙大片/冷蓝科幻/暖怀旧/漂白废土）|
| **材质渲染** | 混凝土（粗糙/光滑/风化）/ 金属（镜面/拉丝/锈蚀）/ 玻璃 / 地面 / 水面 |
| **镜头语言** | 焦距感（广角/标准/长焦）/ 角度 / 景深 / 构图法则 |
| **氛围特效** | 雾密度 / 体积光 / 镜头光晕 / 泛光 / 暗角 / 颗粒 |

**风格关键词串：** 分析完成后，提炼为一句紧凑的关键词串。仅当未通过 @image 锁定风格（需要额外风格约束或换风格）时才写入【风格锚定】；默认 @image 已按「风格DNA提取」锁定风格，此串不写进 prompt。

### Step 3: 场景定位

明确要从参考图中提取什么场景：

1. **目标场景**：哪个位置？（全景建立 / 特定建筑 / 街道层 / 室内等）
2. **排除项**：什么不属于场景？（角色、叙事动作、UI 叠加、角色专属道具）
3. **用户内容覆盖**：如果用户要参考图的风格但不同的场景内容，分离风格（来自参考图）和内容（来自用户描述）
4. **矛盾处理**：如果用户要求与参考图物理逻辑冲突（如"保留霓虹赛博朋克光照但换成中世纪村庄"），标记矛盾但按用户内容 + 参考图色彩/光影逻辑执行

### Step 4: 空间解构

场景没有"正面/侧面/背面"，有的是**空间层**和**替代角度**。

```
前景（距相机最近）：
- 可见元素：[直接可见的前景物体/纹理]
- 纵深功能：[框中框？遮挡元素？比例参照？]
- 主导材质与光线质感：[...]

中景（主体区域）：
- 可见元素：[核心场景特征]
- 视觉锚点：[吸引视线的唯一要素——建筑、光源、地标]
- 主导材质与光线质感：[...]

背景（纵深 / 消失点）：
- 可见元素：[建筑、天际线、山、天空、地平线]
- 纵深处理：[大气透视？锐利细节？剪影？]
- 主导材质与光线质感：[...]
```

### Step 5: 即梦提示词输出

将 Step 1-4 的分析结果填入下方的中文模块化提示词结构。

## 提示词结构（中文）

```
@image [文件名.扩展名] — [参考图类型：风格DNA提取/构图参考]：[具体说明要还原什么、不复制什么]。风格DNA提取模式下，本行即锁定参考图整体风格（色调/笔触/氛围/光影逻辑），后续【风格锚定】默认删除。
（如有多张参考图，每张单独一行 @image 声明）

【Layout 布局 — 来自 hdr_layout_instruction】
16:9 画面，HDR 4面板布局，2×2等分网格，细深色分隔线，面板标签为小号清晰文字。4张照片从同一站立位置拍摄，每转90°拍一张，28mm广角。
左上：正面（0°），主视角方向，场景主视觉。
右上：右侧（90°），右转90°看到的侧面环境。
左下：背面（180°），180°反转看到的来路和背后空间。
右下：左侧（270°），左转90°看到的另一侧环境。

【场景定位】
[场景名称] + [场景类型：室外/室内/半室内] + [叙事功能] + [时间段] + [天气]

【正面 0° — 主视觉】
[空间结构：前景→中景→背景三层] + [建筑特征与材质] + [光源方向与硬度] + [生活痕迹细节] + [比例参照元素] + [主导色调与氛围]

【右侧 90°】
[右转90°看到的画面：侧面墙壁材质、侧面通道、侧光源、不同建筑立面]

【背面 180°】
[180°反转看到的画面：来路、建筑背面、反方向纵深。与正面一起构成场景的进退关系]

【左侧 270°】
[左转90°看到的画面：另一侧环境信息，与右侧对称覆盖360°]

【风格锚定 — 可选，默认删除】
⚠️ 默认不写。若 @image 已按「风格DNA提取」锁定参考图风格，本段整段删除——重复声明风格反而污染画面（风格锚定就是污染提示词）。
仅当未确定按参考图风格走、或需要额外风格约束时，才写：[Step 2 提炼的风格关键词串]

【环境氛围】
[整体氛围基调] + [大气透视处理] + [颗粒物：雾/霾/雨/尘] + [体积光散射]

【环境动态 — 强烈建议】
[风/气流方向与强度] + [受影响元素：旗帜飘动、线缆摇晃、积水涟漪、尘埃飞舞] + [动态带来的画面层次]
（场景概念图的环境动态比角色概念图更重要——它让场景"活着"，而非模型道具。）

【质感说明 — 可选，参考图已锁定时可删】
[关键材质：金属/混凝土/玻璃/水面/石材等。若参考图已精确锁定材质，此模块可省略。]
```

**@image 格式说明：**
- 场景概念图最常用**风格参考**模式：`@image location_ref.png — 风格DNA提取：提取色调、笔触、氛围、光影逻辑。不复制具体建筑布局。不复制参考图中的任何人物，只取场景环境。`
- 若锁定构图：`@image location_ref.png — 构图参考：锁定一点透视和景深结构。不复制建筑风格。不复制参考图中的任何人物，只取场景环境。`
- 多张参考时每张单独一行声明。
- ⚠️ **务必在每张参考图声明中加入"不复制参考图中的任何人物，只取场景环境"**——即梦容易把参考图中的人物一起带过来。

## 完整示例

以下为基于赛博朋克贫民区窄巷参考图的即梦 i2i 场景概念提示词完整示例：

```
@image slum_alley_ref.png — 风格DNA提取：提取赛博朋克湿夜窄巷的色调（深青蓝底+品红霓虹+暖琥珀点缀）、柔和渐变阴影、大气透视、体积光散射。不复制具体建筑布局和招牌文字。不复制参考图中的任何人物，只取场景环境。

【Layout 布局】
16:9 画面，HDR 4面板布局，2×2等分网格，近白色统一背景，细深色分隔线，面板标签为小号清晰文字。4张照片从同一站立位置拍摄，每转90°拍一张，28mm广角。
左上：正面（0°），窄巷主视角方向。
右上：右侧（90°），右转90°看到的侧面环境。
左下：背面（180°），从巷尾看向巷口方向。
右下：左侧（270°），左转90°看到的另一侧环境。

【场景定位】
贫民区主巷，室外，赛博朋克废土城市底层居住区，深夜，刚下过雨，地面湿漉。

【正面 0° — 主视觉】
前景：湿漉的不规则石板地面，积水洼反射霓虹色，边缘散落金属碎片和废弃物。
中景：两侧密集的多层改建模块房——金属板+混凝土+回收材料拼接墙面，外挂管道和通风口，带栏栅的窗户透出冷蓝光。
背景：巷道消逝于大气雾霭中，霓虹招牌（品红横管+病态绿竖牌）渐隐于雾中，消失点在画面中部。
头顶：电线与数据线交织成网，形成部分天篷。
光源：头顶水平霓虹管（品红+青绿），建筑立面暖琥珀壁灯，窗户冷蓝光。
主导色调：深青蓝底色约60%，品红霓虹约25%，暖琥珀约15%。

【右侧 90°】
右转90°看到的画面：右侧建筑的侧面墙面——金属板覆盖混凝土，铆钉，锈迹流痕。一条狭窄的侧面通道通向更深处，墙面有暖琥珀壁灯。地面仍有积水反射霓虹光。头顶线缆密度增加，部分下垂。

【背面 180°】
从巷尾死胡同看向巷口方向。展示建筑背面——不同的窗户排列、半塌的金属遮阳棚、从背面看的闪烁霓虹招牌。巷口通向稍宽的街道，远处建筑剪影。地面仍有积水和水洼。与正面一起构成场景的进退关系。

【左侧 270°】
左转90°看到的画面：左侧建筑的侧面——与右侧对称但不同细节。一个废弃的金属门框半开，墙面有涂鸦和管道。岔巷入口在左侧远处可见。地面湿漉，散落碎屑。

【环境氛围】
幽闭压抑，孤独感。大气透视柔化远景。湿气雾霭弥漫。霓虹体积光散射，光晕柔和泛光。深色区域接近黑但保留细节。

【环境动态】
轻微的冷风沿巷道方向吹过。头顶线缆微微摇晃。地面水洼有细小涟漪。远处霓虹招牌在湿气中轻微闪烁。空气中漂浮细微水珠颗粒，在霓虹光中形成半透明光层。
```

## 与 Gemini/GPT 场景概念 i2i 的关键差异

| 维度 | Gemini/GPT | 即梦 |
|------|-----------|------|
| 语言 | 英文长句复合描述 | 中文短句模块化 |
| 参考图控制 | 纯文字声明 boundaries | 相似度滑块 + 文字声明 |
| 风格锚定 | 长段自然语言风格后缀 | 风格标签 + 短句关键词 |

| 环境动态 | 不专门强调 | 【环境动态】独立模块，强烈建议填写 |

| 布局声明 | 英文 HDR layout instruction | 中文【Layout 布局】模块 |

## 与 frame/jimeng i2i 和 concept/character/jimeng i2i 的关键差异

| 维度 | frame/jimeng | character/jimeng | location/jimeng |
|------|-------------|-----------------|-----------------|
| 目的 | 单帧 cinematic frame | 角色三视图参考 | HDR 4 面板场景概念图 |
| Layout | 单图构图 | 三列等分（面部/正面/背面） | 四面板（正面/右侧/背面/左侧 90°旋转） |
| 环境 | 完整环境氛围+动态 | 纯白背景，无环境 | 环境是主体，【环境氛围】+【环境动态】为核心模块 |
| 参考图模式 | 角色特征/风格参考 | 角色特征（高相似度） | 风格参考（中低相似度）/构图参考 |
| 面部 | 按景别描述 | 左列独立高清面部特写 | 无（场景中人物仅作比例参照） |
| 字数压力 | 中等 | 中等 | **中**——四面板+环境动态，比旧五面板布局更精简 |

## 反向提示词写法（中文）

**宜短不宜长，5–8 个词最佳。** 正面锚定已排除的，反向不再重复。

场景概念图专用反向：

```
文字，水印，多余人物，UI界面，3D渲染，照片质感，模糊
```

**场景概念图反向提示词要点：**
- **多余人物**：场景概念图中不应出现任何人物。即梦容易从参考图中带过来人物，反向提示词中"多余人物"是必须项。
- **文字/水印**：即梦容易在招牌上生成乱码文字
- **3D渲染/照片质感**：如果参考图风格已锁定（未另写风格锚定），或风格锚定已声明"2D平面、手绘质感"，但生成结果仍然偏3D，才在反向中加强
- 如果生成结果没有这些问题，可以**完全不用反向提示词**

## 关键规则

1. **中文优先**：即梦对中文短句模块化描述理解最精准。英文风格关键词串可保留在【风格锚定】中。
2. **Layout 先于内容**：开篇先声明【Layout 布局】的五面板结构，再逐面板撰写内容。
3. **风格参考模式为主**：场景概念图通常用风格参考（30-50%相似度），提取参考图的视觉DNA而非复制具体建筑。必须用文字声明"不复制具体建筑布局"。
4. **环境动态不可忽视**：场景概念图的核心价值之一是展示环境的"生命力"。【环境动态】模块——风、涟漪、线缆摇晃、颗粒漂浮——让场景从模型道具变成活着的空间。即梦对这类中文描述理解很直接。
5. **主视觉锚定一切**：主视觉面板的光照、时间、氛围必须贯穿所有面板，保证一致性。
6. **俯视空间图是工具图**：它的首要任务是清晰展示空间组织和故事位置标注，清晰度优先于氛围渲染。
7. **色板是生产工具**：每个色样必须标注材质语境——"深青蓝"不够，"深青蓝—湿石板地面夜间"才够。
8. **字数超限时的取舍原则**：若 prompt 接近 2000 字上限，按以下优先级删减：
   - 第一删：【质感说明】（参考图已精确锁定材质时）
   - 第二删：【中景细节】从3面板缩减为2面板，每面板1句
