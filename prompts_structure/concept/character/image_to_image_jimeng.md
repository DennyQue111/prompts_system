## Description

即梦（Jimeng）平台的 image-to-image 角色概念设计提示词结构。与单帧 cinematic frame 的 i2i 不同，此结构用于生成**角色参考三视图**——专为视频生成（Seedance / Kling 等）准备的高清角色锚定图。

**核心理念**：上传角色设定参考图，在即梦生成一张 16:9 三列布局的角色参考图（左=面部特写 / 中=正面全身 / 右=背面全身），作为视频模型的输入参考帧。左侧高清面部特写为视频模型提供高分辨率人脸锚点，防止 temporal sampling 过程中的面部漂移和模糊。

**Layout 参考**：`simple_layout_instruction.md`——三列等分水平布局，为视频模型采样优化的简化结构。

**前置必读**：撰写任何 prompt 前，请先阅读 [`meta/prompt-hygiene.md`](../../meta/prompt-hygiene.md) 中的八条横切规则与四问自检清单。GPT 环境下额外阅读 [`meta/gpt-image-hygiene.md`](../../meta/gpt-image-hygiene.md)。

## 即梦 i2i 角色概念工作流

1. **上传参考图**（1–3张：角色概念图、服装参考、风格参考等）
2. **选择参考模式**
   - **角色特征**：高相似度（75–90%），严格锁定面部/发型/体型/服装
   - **风格参考**：中低相似度（30–50%），提取色调/笔触/氛围
3. **写中文提示词**（结构见下方，基于 simple_layout_instruction）
   - ⚠️ **字数限制：即梦 prompt 输入框有 2000 字上限。** 优先保证【Layout 布局】【面部特写】【正面全身】三项，其他模块按需取舍。
4. **调整反向提示词**（中文，5–8 个词）
5. **选择画风标签**（如「动漫」「插画」「概念设计」）辅助锚定

## 提示词结构（中文）

```
@image [文件名.扩展名] — 角色身份锁定：精确还原面部特征、发型、体型、服装款式。不复制背景、构图、表情。
（如有多张参考图，每张单独一行 @image 声明）

【Layout 布局 — 来自 simple_layout_instruction】
16:9 画面，三列等分竖构图，白色或近白色统一背景，细深色竖线分隔。
左列：上半身特写，面部高清，肩部以上，中性表情，均匀柔和光线，面部占据该列大部分高度。
中列：正面全身，自然站立姿态，双臂放松，全套服装清晰可见。
右列：背面全身，展示服装背面、发型背面、背部配饰和标记。

【角色身份】
[角色名] + [年龄/身份] + [核心视觉标签]

【左列 — 面部特写】
细化面部：[脸型] + [五官特征] + [眼型/瞳色] + [眉形] + [鼻型] + [唇形] + [肤色质感]
细化发型：[发色/发质/长度/造型]，从面部特写角度可见的发型细节
面部标记：[疤痕/痣/纹身/雀斑等]，如有

【中列 — 正面全身】
[体型/身材比例] + [站姿] + [气质/体态语言]
[服装自上而下描述] + [配饰] + [鞋履]
[全身比例关系：头身比/肩宽/腿长等]

【右列 — 背面全身】
[服装背面结构] + [发型背面] + [背部可见的配饰/标记]
[与正面一致的身材比例]

【风格锚定】
[直接引用项目 style_profile.md 的核心中文描述，或即梦风格标签]
推荐：polished 2D anime key visual, 手绘质感，完成度高，2D平面，数字绘画完成品，角色设定参考图

【环境 — 此模板为空或极简】
纯白背景，无环境元素，无地面，无阴影投落。
（角色参考图不需要环境叙事，专注于角色本身。）
```

## 完整示例

以下为基于小武角色的即梦 i2i 角色概念提示词完整示例：

```
@image xiaowu_ref.png — 角色身份锁定：精确还原面部特征、发型、体型、深色西装款式。不复制背景、构图、表情、动作。

【Layout 布局】
16:9 画面，三列等分竖构图，白色背景，深灰色细竖线分隔。
左列：上半身特写，面部高清，锁骨以上，中性表情，均匀柔和正面光，面部占据左列大部分高度。
中列：正面全身，自然站立，双臂放松垂于身侧，全套服装清晰完整。
右列：背面全身，展示西装背面结构、短发背面、背部轮廓。

【角色身份】
小武，28岁，办公室职员被卷入死亡游戏，宽脸诚实面相，马东锡式壮实身材

【左列 — 面部特写】
脸型方正偏宽，下颌线条清晰但不锐利，额头宽阔。
单眼皮，眼型细长但眼神直接坦率，深棕色瞳孔。
眉形粗直，自然生长不刻意修剪，眉间距适中。
鼻梁挺直，鼻头圆润不尖锐。
嘴唇偏厚，下唇略突出，嘴角自然微垂（非刻意严肃，只是放松状态）。
肤色偏暖黄调，东亚肤质，无粉底无修饰，自然质感。
短发黑色，略微凌乱的偏分，发质粗硬，发尾不规则。
无面部标记。

【中列 — 正面全身】
体型魁梧壮实，倒三角上身，肩宽胸厚但不臃肿，有明显肌肉量但非健美选手式的低体脂——是实用型的力量感。
站姿放松但体态有下意识的警觉：重心略偏前脚掌，肩膀微微内收，像随时准备行动。
深色西装（由婚礼西装改造而来）：外套略紧绷（因体型较壮），肩部和上臂处有明显拉伸褶皱；内搭白衬衫，领口松开一颗扣子，不系领带；西装裤笔直但膝盖处有轻微坐姿褶皱；黑色皮鞋，鞋头有轻度磨损。
身高约178cm，头身比约7.5头身，肩宽突出。

【右列 — 背面全身】
西装外套背面：中缝笔直，肩胛骨区域有轻微横向拉伸褶皱（因肌肉量），下摆自然垂落至大腿中部。
短发背面：后颈发际线整齐，发尾层次不齐，枕骨区域头发略厚。
裤装背面：臀部和大腿处有轻微坐姿褶皱，裤脚自然落在鞋面上方。
无背部配饰，无背部标记。

【风格锚定】
polished 2D anime key visual, 手绘质感，厚涂完成品，2D平面，数字绘画完成品，角色设定三视图参考，非3D渲染，非真实感，非矢量扁平，绝非草图，完成度高

【环境】
纯白背景，无环境元素，无地面线，无阴影投落。
```

## 与 GPT/Gemini 即梦提示词的关键差异

| 维度 | frame/jimeng i2i | concept/character/jimeng i2i |
|------|-----------------|------------------------------|
| 目的 | 单帧 cinematic frame | 角色三视图参考（视频输入用） |
| Layout | 单图构图描述 | simple_layout_instruction 三列等分 |
| 面部 | 按镜头景别自然描述 | 左列独立高清面部特写面板 |
| 环境 | 完整环境氛围+动态 | 纯白背景，无环境 |
| 服装 | 按镜头可见范围描述 | 正+背双面完整描述 |

## 反向提示词写法（中文）

**宜短不宜长，5–8 个词最佳。** 正面锚定已排除的，反向不再重复。

角色概念图专用反向：

```
文字，水印，多余人，复杂背景，阴影投落，地面，道具
```

如果风格锚定已声明"非3D渲染、非真实感"，反向无需再写。如果生成结果没有这些问题，可以完全不用反向提示词。

## 关键规则

1. **中文优先**：即梦对中文短句模块化描述理解最精准。
2. **Layout 先于内容**：开篇先声明三列等分布局，再逐列撰写面板内容。
3. **面部特写是第一优先级**：左列描述应最详细——这是视频模型的面部锚点，模糊不得。
4. **三列风格一致**：正面和背面的渲染质量、光线、细节程度必须匹配，模型会交叉参考。
5. **纯白背景不要省**：环境描述里明确写「纯白背景，无地面，无阴影」——即梦容易自动加地面和环境。
6. **表情中性**：这是参考图，不是表演。情绪留给 shot 级 prompt。
7. **相似度≠一切**：高相似度锁定面部特征，但要用文字声明「不复制背景、构图、表情」。
8. **风格标签辅助**：即梦的「动漫」「插画」预设标签 + prompt 内风格声明双重锚定。
9. **字数超限时的取舍**：优先保留【Layout 布局】【面部特写】【风格锚定】，【背面全身】可精简，【环境】本来就很短。
