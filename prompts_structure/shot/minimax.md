# Shot · MiniMax H3 单镜头视频生成

## 是什么

Shot (MiniMax H3) 是专为 MiniMax H3 模型设计的**单镜头视频提示词结构**。与 Sequence 的完整 15 秒时间轴不同，Shot 聚焦一个独立镜头的生成——通常 5—10 秒，绑定一张关键帧参考图，描述这一个镜头内的画面、运动、声音与节奏。

适用场景：单镜头测试、关键帧动效验证、独立镜头生成后手动拼接。

## Performance 前置步骤（必做）

生成 MiniMax H3 单镜头提示词前先读取 `performance/README.md`，并按当前角色读取 `acting_master_profile.md`、`eye_life.md`、`scene_adaptation.md`。把表演规则写入画面、动作、情绪和声音描述：有人脸时明确视线目标、扫描顺序、微跳视、眨眼、catchlights 及目光→头部→身体的先后；多人逐人指定看谁；武戏按预备→发力→峰值→回收→恢复写物理因果；区分摄影机左右、角色自身左右和武器/义肢切换时机。

与 Seedance Shot 的核心差异：H3 Shot 保留**原生立体声设计**、**以内联图片引用**和**严格标点语法**组织提示词。约束与对白写法见下方核心原则及对应章节。

---

## 核心原则

1. **参考图管视觉，文字管物理+摄影机+声音。** 图片锁定人物身份、服装、材质、场景与色彩；文字只描述运动、力学、镜头行为与声音。i2v 模式下不写视觉风格词。
2. **提示词聚焦目标画面。** 正文只写本镜希望出现的内容与动作；不要预先列举画面里没有、也未发生过的问题对象，负面约束也一样。只有生成结果已出现具体且需要修正的问题时，才在末尾加一条简短、针对该问题的修正约束，并避免在正文重复点名。若接口没有独立负面字段，这段文字仍属于同一个 prompt，不是独立的负面条件。
3. **运镜是灵魂。** 固定、缓推、横摇、手持跟拍、升降、拉远、环绕、甩镜、变焦推。每个单镜头明确选择。
4. **焦距影响空间感。** 35mm 拉伸纵深、85mm 压缩平面。焦距独立于运镜。
5. **动作描述靠物理，不靠形容词。** 质量如何分布、力从哪来、材质如何响应、肢体如何恢复。
6. **有人就写情绪。** 画面中能看清人物时写调性关键词；无人省略。
7. **光影变化单独写。** 不变写"持续不变"；有变化具体描述。
8. **首帧即戏。** 第一帧锁定清晰、内容确定的画面——角色已在镜头中，动作已在发生。
9. **声音是一等公民。** H3 生成原生立体声，声音设计独立成段。
10. **前景物件空间锚定（正向版）。** 可交互的前景物件在画面内容中声明"位置与形态固定不变，始终保持为X"。
11. **速度与空间分开锁定。** 需要常速或高速运动时，先明确主体在第一帧已进入运动、以何种现实速度移动、在镜头结束前完成什么可见位移；再单独锁定摄影机和场景拓扑。不要让“主体明显驶远”和“摄影机跟拍穿越复杂空间”在同一短镜头内同时成为主要变化。

## 输入结构

### 图片内联引用

单镜头通常只有一张关键帧参考图，编号为图片1。图片引用跟在对象名称后，使用全角括号：

```
义肢少年（@图片1）
赛博朋克后巷（@图片1）
```

**规则：**
- 开篇的人物/主体/场景锁定段建立图片绑定
- 后续正文第一次出现相关对象时延续（@图片1）引用
- 一张图片包含多个主体时分别标注：`主角（@图片1）与同伴（@图片1）`
- 无图片时直接从"生成一段X秒……"开始

### 参考图绑定格式

```
## 人物与场景锁定

主体名称（@图片1）— 锁定该图片覆盖范围内的全部视觉身份：面部特征、发型、体型、服装款式、装备、材质与色彩。后续正文中该主体出现时延续（@图片1）引用。
```

### 多图上传顺序：镜头画面优先，概念图在后

当同一次 H3 生成同时使用**镜头 frame / keyframe**与**角色概念图**时，按以下顺序上传并在开篇锁定段中写清用途：

1. 图片1：镜头 frame 或 keyframe——作为视频开场画面、机位、构图和场景空间的主参考。
2. 图片2（及其后）：角色概念图——只锁定人物身份、面部、服装与关键设定，不是视频画面、首帧或转场素材。

这是经过实际 i2v 验证的默认策略：将角色概念图置于后位，并明确其仅作身份锚定，可降低 H3 把概念图误当成开场画面、再向镜头 frame 叠化过渡的概率。

构图/布局由关键帧承担，角色概念图补充身份、脸、服装和材质细节；概念图是设计参考，不会增加视频输出分辨率，也不保证微小细节完整迁移。若使用多格动作/机位图，按 `storyboard/core.md` 生成简洁黑白线稿，只让它传递动作顺序与机位变化；获批关键帧/场景概念图仍是固定场景结构（如雕塑轮廓）的权威。提示词明确分图职责，并在提交前核对参考图本身没有携带与目标冲突的设计。

```text
镜头画面（@图片1）— 作为本镜第一帧与构图参考，锁定机位、空间、人物在画面中的起始位置。
角色概念图（@图片2）— 仅锁定角色身份、脸、服装和设定；视频从（@图片1）的镜头画面直接开始，角色概念图不作为画面或转场。
```

若角色概念图是唯一参考图，则正常作为图片1 使用；若 frame 是终点或中间动作姿态而非首帧，仍将 frame 放在图片1，并在画面内容首句另行写清视频的实际第一帧。

### MiniMax H3 首帧锚点与提示词标签（执行层）

- `@图片N` 是项目提示词的可读写法；提交给本地 MiniMax H3 节点前，后端会转换为节点识别的 `<Picture N>` 标签。不要仅靠自然语言写“唯一首帧”来实现硬首帧约束。
- 镜头图确实要锚定第0帧时，执行请求必须把它单独传入 `first_frame_image`；人物/外观概念图继续按顺序放进 `reference_images`。只传 `reference_images` 走的是 Ref2VA，图像是参考而非精确首帧。
- 同时传 `first_frame_image` 与 `reference_images` 时，执行层使用 Ref2VA + 官方 `MiniMaxH3AddGuide`：首帧作为 `Picture 1` 进入参考序列，并由 AddGuide 单独锚定在视频 frame 0；后续人物/外观参考从 `Picture 2` 开始。不要把它描述成 T8 节点原生 Hybrid 模式。
- 该组合最多 9 张 Picture 图，首帧占 1 张，因此额外人物/外观参考最多 8 张。仅传首帧走 I2VA；仅传参考图走 Ref2VA。
- 首帧锚定把图像条件放在时间轴第0帧，但仍是生成模型条件，不承诺输出像素级复制；提示词要继续描述从该构图如何自然开始动作。

## 首帧占用规则

视频模型的前 1—2 秒是"预热期"——如果不明确声明，模型倾向用模糊空镜或缓慢 fade-in 填充。

```
✅ "第一帧：义肢少年（@图片1）已站在巷道中段，右臂铜色义肢垂在身侧，正沿巷道向前行走。"
❌ "画面中是一条雨夜巷道，少年随后出现并开始行走。"
```

| 规则 | 说明 |
|------|------|
| 角色在第一帧可见 | 如果镜头要拍角色，第一帧就有角色 |
| 动作在第一帧已在发生 | 角色在第一帧已处于动作进行态，不写"静止→开始动" |
| ≤6秒的镜头绝对禁止空镜建立 | 短镜头没有时间浪费——第一帧就是戏 |

## 单镜头模板

```markdown
### {shot_id} · {中文简述} · {时长}

- **画面内容**：[画面里有什么——谁、在哪、在做什么。纯物理描述，不写风格词。首句锁定第一帧内容，遵守首帧占用规则。人物/主体/场景首次出现时使用内联图片引用（@图片N）。]
- **焦距**：[具体焦距 mm，如 35mm / 50mm / 85mm；或焦段如 24–35mm。写变化路径如有变焦]
- **运镜**：[固定 / 缓推 / 横摇 / 手持跟拍 / 升降 / 拉远 / 环绕 / 甩镜 / 变焦推；可组合]
- **动作**：[镜头内发生了什么事——物理描述，含质量感、力的来源与传递、材质响应、肢体恢复。武戏按因果链写：A—B—C—D]
- **情绪**：[有人物时写调性关键词；无人省略整行]
- **光影变化**：["持续不变" 或具体描述变化内容和时机]
- **衔接**：[切 / 叠化 / 淡入淡出 / 闪白 / 独立测试镜头省略整行]
```

### 字段约束

| 字段 | 必填 | 写法 |
|------|------|------|
| **画面内容** | ✅ | 纯物理描述，禁止风格词；首句锁定第一帧；内联图片引用 |
| **焦距** | ✅ | 具体 mm 数或有意义的焦段范围 |
| **运镜** | ✅ | 从选项列表中选，可组合 |
| **动作** | ✅ | 物理描述 + 节奏词；武戏按因果链写 |
| **情绪** | 看情况 | 有人物就写，无人省略整行 |
| **光影变化** | ✅ | "持续不变" 或具体写 |
| **衔接** | 看情况 | 独立测试镜头省略整行 |

## 画面内容中的空间锚定（正向版）

视频模型在镜头运动时倾向于对画面内容逐帧"重新解释"——前景物件可能漂移、变形、被替换。空间锚定是对抗此倾向的核心手段。

**H3 版写法——三重正向声明：**

```
画面内容：……义肢少年（@图片1）站立于圆形工作台前。工作台为圆形树桩横截面，直径约80cm，位置与形态固定不变，始终保持为木质树桩工作台。工作台前方约60cm处有一只三足小木凳，高约20cm，位置与形态固定不变，始终保持为同一只木凳。……
```

三重声明结构（全正向）：
1. **物件 + 空间位置描述 + 尺寸**（在哪、什么形态、多大）
2. **"位置与形态固定不变"**（硬锁定——正向表述）
3. **"始终保持为[物件名称]"**（防物件替换——正向表述）

关键物件包括但不限于：
- 角色将要交互的物体（工作台、凳子、工具、武器）
- 画面中持续存在的前景元素（火坑、门、窗、光源）
- 任何在镜头中需要被角色物理接触的物件

> 不是所有物件都要写——背景建筑/树木/天空等通过参考图锁定的元素不需要逐一声明。只对"镜头内可见、且角色可能交互或靠近"的前景元素做三重声明。

## 动作描述

### 连续全景

需要整镜保持全景时，在首句锁定首帧构图，并明确全程保留的主体与空间锚点；动作尽量归纳为少数连续阶段，避免逐人拆出容易被模型理解为切镜的反应拍子。若成片实际切成特写，再在下一版加一句针对切镜/景别变化的短修正。此做法来自个案经验，不保证完全锁镜。

### 速度与场景连续性

MiniMax 容易把未量化的动作处理得过慢；主体大幅移动且摄影机同步推进时，也可能逐帧重绘道路、建筑或地面，造成拓扑断裂。速度、运镜和空间稳定性必须分别写清。

**常速/高速的正向写法：**

```text
动作：黑色轿车在第一帧已处于行驶状态，以正常城市车速持续加速，四秒内沿同一车道向消失点驶出一段清晰可见的距离；尾灯、轮胎水花和路面倒影随速度连续后移。
```

避免使用会默认放慢节奏的词：`slowly`、`subtle`、`gentle`、`gradual`、`lingering`。H3 使用全正向描述；不要用 `no slow motion` 之类的否定句来补救。

**高速主体 + 复杂场景的稳定写法：**

```text
运镜：固定高机位，全程不移动。
画面内容：高架路从前景连续延伸至远处消失点；车道线、两侧混凝土护栏、楼体和电线位置与形态固定不变，始终保持为同一条完整高架道路。
动作：轿车沿同一车道驶远。
```

- 优先选择一个主要变化：主体移动、摄影机移动或环境变化三者通常只选一个作为主动作。
- 若必须跟拍，使用较短位移、明确的起止位置，并减少画面中需要持续重建的道路、建筑和电线。
- 出现地面断裂、道路分叉、建筑替换等问题时，先改为固定机位测试；不要仅靠增加速度词重试。

### 文戏/静态镜头

自由描述，注重物理细节和节奏：

```
动作：少年以小步幅沿巷道前进，右臂义肢因重量产生轻微惯量摆动，每一步落地靴底踩入浅水洼溅起细小水花。约第二步后步伐明显减速——先是右脚落地后停顿比正常步态长半拍，然后左脚并拢，身体重心从前脚掌移回后脚跟，双肩微微上提。
```

### 武戏/动作戏：因果链

按因果箭头链写——每个动作的受力直接成为下一动作的动力来源：

```
动作：她身体下潜闪避—重心压到前脚掌—髋部带动肩膀转出—脚掌碾碎湿落叶—拳套逼近镜头形成压迫—拳风带起松散毛发—防守手立即回位—前臂微颤显示力量残留—快速起身横移两步回到guard stance—胸廓随呼吸起伏。
整体爆发力强，节奏由缓到急再回收。
```

> 核心是"动作有始有终"——打完要收、发力后要恢复。物理细节比形容词更能让模型理解运动。

## 焦距选项

```
24mm–35mm → 广角：拉伸纵深，适合动作跟拍、空间展示、环境沉浸
50mm → 标准：接近人眼，适合对话、中性观察
85mm+ → 长焦：压缩空间，适合特写、极端情绪、攻击性逼近
变焦 → 如 50mm→35mm：镜头内焦距变化，伴随空间感转变
```

## 运镜选项

```
固定 → 机位不动，画面静止
缓推 → 画面缓慢向前推进，增强沉浸感
横摇 → 水平方向旋转，展示环境或跟随移动
手持跟拍 → 模拟手持摄影机，轻微抖动，纪实感
升降 → 垂直方向移动，改变视角高度
拉远 → 画面向后拉，从主体退到更大场景
环绕 → 围绕主体旋转，展示空间关系
甩镜 → 快速从一个主体甩到另一个
变焦推 → 焦段变化而非机位移动，压缩空间感
```

## 衔接选项

```
切 → 硬切，最常用
叠化 → 两镜重叠渐隐，过渡自然或暗示时间流逝
淡入淡出 → 黑场过渡，段落感强
闪白 → 强光瞬间覆盖画面，冲击/记忆/转换
省略整行 → 独立测试镜头或最后一个镜头不写衔接
```

## 对白（有台词时）

每句实际说出口的台词原文在整份提示词正文中**只出现一次**，集中写在这个区块。写清说话者、原文、语言、时间窗、语气/音质与口型同步。动作描述只写“说出本镜对应台词”或描述说话动作，不复述原文；声音设计不再引用或改写台词内容。无台词时省略此区块。

```text
## 对白
- **说话者**：[角色名]
- **台词原文**：[原文只在此处出现一次]
- **语言与表达**：[语言、语气、音质]
- **时间窗**：[开始—结束秒数]
- **口型同步**：[与该句同步]
```

## 声音设计

H3 生成原生立体声，即使单镜头也需要声音设计。放在画面描述之后；对白原文与时间窗已单列，不在本段重复。

```
## 声音设计

- **环境声**：[持续背景音——雨声密度、风声方向、远处嗡鸣等]
- **动作声**：[关键动作音效——金属碰撞质感、布料摩擦、脚步落地材质等与本镜可见动作相符的声音]
- **音乐**：[有无配乐、乐器类型、节奏特征。无配乐写 —]
- **声音空间感**：[声源方位——左/右声道、远/近、移动轨迹]
```

### 配乐规则

- **2D 动画风格场景默认无配乐**：音乐字段写 "—"
- **写实/电影感场景**：根据剧情需要决定
- 用户说"不要背景音乐"或"无配乐"时，音乐字段必须写 "—"
- 用户未提及配乐时：2D 动画→默认 —，其他风格→根据剧情判断

### 对白标点规则

双引号（中文""或英文""）**只**标记角色实际说出口的台词：

```
✅ 少年低声说："别回头。"
❌ "温柔克制"（情绪概念不用引号）
❌ "手持跟拍"（镜头名称不用引号）
```

| 破折号 — | 动作因果链连接 | 观察后视镜—发现追兵—移开手臂 |
| 冒号 ： | 段落标题 | 声音设计： |
| 顿号 、 | 并列项 | 目光停顿、呼吸变化、手部动作 |
| 全角括号 （） | 图片内联引用 | 义肢少年（@图片1） |

**禁止**：用双引号标记动作链、镜头名称、段落标题、情绪概念或强调内容。

## 成品输出顺序

最终提示词按以下顺序组织，可直接复制进 MiniMax H3：

```
1. 开篇规格行："生成一段X秒、16:9、2K、原生立体声……[镜头概述]"
2. 人物与场景锁定段（内联图片引用）
3. 画面内容 / 焦距 / 运镜 / 动作 / 情绪 / 光影变化
4. 对白（有台词时）：每句原文只出现一次
5. 声音设计：[环境声 / 动作声 / 音乐 / 声音空间感；不复述对白原文]
```

单镜头输出比 Sequence 精简——无需全片设定、摄影机运动总览和摄影动机。核心是画面描述 + 声音设计。

## 交付前自检

- [ ] 人物、服装、装备、主体和场景是否与参考图一致
- [ ] 首帧是否锁定清晰内容（角色已在、动作已在发生）
- [ ] 前景可交互物件是否做了正向空间锚定声明
- [ ] 需要常速或高速时，主体是否在第一帧已运动，并写明速度类型与镜头内可见位移结果
- [ ] 主体移动、摄影机移动、环境变化中是否只指定了一个主变化；复杂场景是否已锁定道路/建筑等拓扑
- [ ] 对白区块（如有）是否写清说话者、原文、时间窗、表达和口型同步，且每句原文只出现一次
- [ ] 声音设计是否完整（环境声 / 动作声 / 音乐 / 声音空间感），且不重复对白原文
- [ ] 双引号是否只出现在角色实际说出口的台词中
- [ ] 提示词是否聚焦目标画面；是否避免预先列举尚未在生成结果中出现的问题
- [ ] 若加入负面修正，是否针对已观察到的具体问题，且足够简短；是否确认它是独立字段还是同一 prompt 文本
- [ ] 图片引用是否以内联形式紧跟对应对象
- [ ] 输出是否为 H3 可直接复制的自然语言提示词

---

## 使用时

1. 让对方**先发参考图并说明这张图是什么**
2. 生成时，**第一部分永远是人物与场景锁定段**（内联图片引用格式）
3. 然后填写单镜头模板——画面内容首句锁定第一帧，遵守首帧占用规则
4. 追加**声音设计**
5. 单镜头通常只有一张参考图，不需要考虑多图区域对应问题
6. 如果对方没说明时长，默认 5—10 秒；如果对方没说明运镜倾向，主动问——别猜

## 与 Seedance Shot 的关键差异

| 维度 | Seedance (shot/seedance.md) | MiniMax H3 (本文件) |
|------|------|------|
| 声音 | 无声音设计 | 独立声音设计段（环境/动作/对白/音乐/空间感） |
| 约束方式 | 按需使用分离的 negative prompt 区块 | 以目标画面描述为主；负面修正仅用于处理已观察到的问题 |
| 图片引用 | @image 块式声明 | 主体（@图片N）内联引用 |
| 标点规则 | 无特定标点规则 | 严格标点语法（双引号只用于台词） |
| 空间锚定 | 三重声明（含"禁止变成X"） | 三重正向声明（"始终保持为X"） |
| 首帧规则 | 无（Seedance Shot 未设此规则） | 有（第一帧锁定清晰内容） |
| 输出格式 | 结构化 Markdown | 自然语言段落，可直接复制进 H3 |
