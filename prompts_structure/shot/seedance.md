# Shot · 单镜头视频生成

## 是什么

Shot 是**单个镜头的视频生成提示词**。与 Sequence 不同，它不需要描述全片设定，只需要把这一个镜头的画面内容、运动、节奏、情绪说清楚。

单镜头通常绑定一张关键帧参考图，提示词的核心任务是：告诉视频模型这张图上的人/物应该怎么动、镜头怎么运动、氛围怎么维持。

---

## ⚠️ 字数限制

**Seedance 提示词上限 4000 字符。** 单镜头提示词通常不会超限，但如果有关键帧参考图声明 + 详细动作描述 + style-profile 注入 + 负面约束，仍需注意。

### 精简策略

1. **参考图声明精简**：一张图一行，说清"是什么 + 锁什么"即可
2. **动作描述聚焦**：只写这个镜头内的核心动作，不写前因后果
3. **运动质感说明**：如有 style-profile 注入，用标准注入块的精简版
4. **负面约束**：只保留 3-5 条最关键的禁止项

---

## 核心原则

1. **参考图管视觉，文字管物理+摄影机。** 风格、色调、材质、渲染方式——参考图已经锁死了。文字不描述任何风格，只描述运动、力学、光线变化、镜头行为。风格词的唯一归宿是参考图本身。
2. **运镜是灵魂。** 视频区别于静帧的本质是"怎么动"——固定、缓推、横摇、手持跟拍、升降。每一个单镜头都要明确选择。
3. **焦距影响空间感。** 35mm 的空间关系跟 85mm 完全不同——广角拉伸纵深、长焦压缩平面。焦距是独立于运镜的一级字段。
4. **动作描述靠物理，不靠形容词。** 告诉模型质量如何分布、力从哪来、材质如何响应、肢体如何恢复——不是"激烈打斗"，而是"矛击自沉髋发力，过接触点后继续延伸，需可见恢复步"。
5. **有人就写情绪。** 画面中能看清人物时，加情绪关键词帮助模型理解表演调性；无人省略整行。
6. **光影变化单独写。** 光线从头到尾不变就写"持续不变"；有变化就描述。
7. **参考图说清用途就不再重复。** 前面写清楚图管什么后，画面内容直接描述画面本身。
8. **前景物件空间锚定。** 视频模型在逐帧生成时会倾向于重新解释模糊空间——物体会漂移、变形、被替换成其他物件。对抗这个倾向的方法：画面中所有可在镜头内被交互的前景物体（工作台、凳子、工具、火坑等），必须在画面内容中明确声明"形态与位置固定不变"+"保持为X，不变成Y"。这不是多余的废话——是防止模型 object hallucination 的硬护栏。

## 输入结构

参考图描述块，用 `@image` 格式。每张图一行说清：是什么 + 管什么 + 不管什么。

```
## 参考图

@image [文件名.扩展名] — [名称]关键帧。本图锁定全部视觉风格、色调、材质、渲染方式，同时锁定前景所有物件的形态与位置。文字只负责运动、力学与镜头行为。

@image [文件名.扩展名] — [名称]HDR 场景图——2×2 等分布局，4 个面板分别为：左上=正面(0°)、右上=右侧(90°)、左下=背面(180°)、右下=左侧(270°)。每个面板是该位置朝对应方向的 28mm 广角环境照。本图锁定场景的环境风格、建筑特征、光源方向和空间关系。
```

**单镜头通常只有一张关键帧参考图**，描述简洁明确即可。

### @image 面板引用

当参考图为 HDR 场景图（2×2 四面板）时，在**画面内容**字段开头用 `@image [文件名] [面板位置]` 引用与本镜头方向最接近的面板。

**HDR 面板位置对照：**

| 写法 | 对应面板 | 方向 |
|------|---------|------|
| `左上` | 左上面板 | 正面 0° |
| `右上` | 右上面板 | 右侧 90° |
| `左下` | 左下面板 | 背面 180° |
| `右下` | 右下面板 | 左侧 270° |

**示例：**

```
### SHOT 01 · 小武走入巷道 · 0-3s
画面内容：@image scene001_location.png 左上 贫民区巷道。小武背影在画面下方，背对镜头沿巷道行走。
```

如果镜头中同时涉及角色和场景，分别引用：
```
画面内容：@image scene001_location.png 右上 贫民区巷道。@image XiaoWu_concept.png 小武。小武侧面走过右侧建筑…
```

**规则：** `@image` 后必须带角色名或场景名（如 `小武`、`贫民区巷道`），不能只写"参考角色设计"——多角色场景下模型无法区分。

## 镜头模板

```markdown
### {shot_id} · {中文简述} · {时长范围}

- **画面内容**：[画面里有什么——谁、在哪、在做什么。纯物理描述，不写风格词，不写「基于 Image X」]
- **焦距**：[具体焦距 mm，如 35mm / 50mm / 85mm；或焦段如 24–35mm。写变化路径如有变焦]
- **运镜**：[固定 / 缓推 / 横摇 / 手持跟拍 / 升降 / 拉远 / 环绕 / 甩镜 / 变焦推；可组合如"低位手持跟拍 + 短后拉"]
- **动作**：[镜头内发生了什么事——物理描述，含质量感、力的来源与传递、材质响应、肢体恢复。武戏/动作戏按五段弧写]
- **视觉母题**：[（可选）一句抽象视觉锚点，如"暗色矛线切分画面"。动作戏建议写，静态镜头可省略整行]
- **情绪**：[有人物时写调性关键词，如"温柔克制"、"压抑恐惧"；无人省略整行]
- **光影变化**：[从头到尾不变 → "持续不变"；有变化 → 具体描述变化内容和时机]
- **衔接**：[切 / 叠化 / 淡入淡出 / 闪白 / 如果是独立测试镜头省略整行]
- **负面约束**：[（可选）本镜需要规避的错误，如"禁止镜头乱晃"、"禁止出现第二个人"]

> **音频控制**：Seedance 可能自动生成背景音频。如不需要背景音乐，在负面约束中加入"无背景音乐"。如需特定声效，在动作描述中用括号注明。
```

### 字段约束

| 字段 | 必填 | 写法 |
|------|------|------|
| **画面内容** | ✅ | 纯物理描述，禁止风格词（anime、cel shaded、illustration 等） |
| **焦距** | ✅ | 具体 mm 数或有意义的焦段范围 |
| **运镜** | ✅ | 从选项列表中选，可组合 |
| **动作** | ✅ | 物理描述 + 节奏词；武戏/动作戏按五段弧写 |
| **视觉母题** | 看情况 | 动作戏建议写；静态镜头省略整行 |
| **情绪** | 看情况 | 有人物就写，无人省略整行 |
| **光影变化** | ✅ | "持续不变" 或具体写 |
| **衔接** | 看情况 | 独立测试镜头省略整行 |
| **负面约束** | 看情况 | 有需要规避的点就写，没有省略整行；空间漂移类模板见下方 |

### 画面内容中的空间锚定

视频模型在镜头运动时倾向于对画面内容进行逐帧"重新解释"——前景物件可能随镜头推进而变形、移位、或直接变成其他物体。空间锚定是对抗这个倾向的核心手段。

**对前景关键物件的写法——三重声明：**

```
画面内容：……画面中央偏下位置，一只人形啄木鸟精灵站立于圆形工作台前，工作台为圆形树桩横截面，台面嵌有天然磨石，散落骨制工具。工作台位置与形态固定不变。工作台前方（画面下方偏左位置）有一只低矮的三足小木凳，小木凳的位置与形态固定不变，不会变成其他物体。画面下方偏右有一处小型地面火坑，位置与形态固定不变。……
```

三重声明结构：
1. **物件 + 空间位置描述**（在哪、什么形态）
2. **"形态与位置固定不变"**（硬锁定）
3. **"不会变成 X / 不变成其他物体"**（防物件替换——可选但强烈建议）

关键物件包括但不限于：
- 角色将要交互的物体（工作台、凳子、工具、武器）
- 画面中持续存在的前景元素（火坑、门、窗、光源）
- 任何在镜头中需要被角色物理接触的物件

**不是所有物件都要写**——背景建筑/树木/天空等通过参考图锁定的元素不需要逐一声明。只对"镜头内可见、且角色可能交互或靠近"的前景元素做三重声明。

### 动作描述：五段弧（武戏/动作戏专用）

**仅当镜头涉及打斗、格斗、剧烈肢体动作时使用。** 文戏/静态镜头沿用自由描述。

按真实动作逻辑描述五段：**预备 → 发力 → 峰值 → 回收 → 恢复**。

每个阶段加入物理细节：质量如何转移、哪个关节驱动、材质如何响应、惯量如何处理。

```
动作：她身体下潜闪避——重心压到前脚掌，髋部带动肩膀转出，脚掌碾碎湿落叶（预备→发力），
拳套短暂逼近镜头形成压迫感，拳风带起松散毛发（峰值），
拳打出后防守手立即回位，前臂微颤显示力量残留（回收），
快速起身+横移两步回到 guard stance，胸廓随呼吸起伏（恢复）。
整体爆发力强，节奏由缓到急再回收。
```

> 五段弧的核心是"动作有始有终"——打完要收、发力后要恢复。不要让动作悬浮在半空或无缝无限循环。物理细节（质量感、材质响应、力量传递路径）比形容词更能让模型理解运动。

### 焦距选项

焦距直接影响空间压缩感和画面张力。选择时考虑：

```
24mm–35mm → 广角：拉伸纵深，适合动作跟拍、空间展示、环境沉浸
50mm → 标准：接近人眼，适合对话、中性观察
85mm+ → 长焦：压缩空间，适合特写、极端情绪、攻击性逼近
变焦 → 如 50mm→35mm：镜头内焦距变化，伴随空间感转变
```

### 运镜选项

```
固定 → 机位不动，画面静止
缓推 → 画面缓慢向前推进，增强沉浸感
横摇 → 水平方向旋转，展示环境或跟随移动
手持跟拍 → 模拟手持摄影机，轻微抖动，纪实感
升降 → 垂直方向移动，改变视角高度
拉远 → 画面向后拉，从主体退到更大场景
环绕 → 围绕主体旋转，展示空间关系
甩镜 → 快速从一个主体甩到另一个
变焦推 → 焦段变化而非机位移动，压缩空间感
```

### 衔接选项

```
切 → 硬切，最常用
叠化 → 两镜重叠渐隐，过渡自然或暗示时间流逝
淡入淡出 → 黑场过渡，段落感强
闪白 → 强光瞬间覆盖画面，冲击/记忆/转换
省略整行 → 独立测试镜头或最后一个镜头不写衔接
```

### 负面约束：空间漂移类模板

视频模型常见的空间错误类型，按需选用。非必填——根据本镜风险选择相关禁令。

**背景/建筑漂移（镜头运动时高发）：**
```
禁止镜头推进时背景建筑结构发生变形、重组或像素闪烁
禁止镜头运动时背景中出现参考图中未有的新结构、新光点或新物体
禁止镜头运动导致前景或背景物体凭空生成新的纹理或细节
```

**物件替换（角色交互时高发）：**
```
禁止[物件A]在任何时刻改变位置、形态或变成其他物体
禁止[物件A]被其他物体替换
禁止角色未物理移动到[物件A]旁就执行与该物件相关的动作（如未走到凳子旁就坐下、凳子被替换成石块）
```

**角色运动漂移（位移+落地时高发）：**
```
禁止角色行走/奔跑/跳跃时脚与地面产生滑步或漂移
禁止角色未水平移动到目标位置就原地执行到达目标位置后的动作
禁止角色空中跳跃后落点与预定目标位置不一致
```

**物件形变（持续可见时高发）：**
```
禁止[物件A]在整个镜头中发生任何形状、颜色或大小的改变
禁止[物件A]在镜头推进过程中因透视变化而被模型重新解释为不同物体
```

## 风格与氛围的写法

**i2v 模式下不写风格。** 参考图已经携带全部视觉风格信息（色调、材质、渲染方式）。文字中写风格词只会造成图文冲突。

如果本镜头需要明确的氛围锚定或光影基调，**在画面内容中用纯视觉事实交代**（色温、光比、可见元素），不使用风格标签。

```
画面内容：暖赭石地面 vs 冷蓝天空的高对比色调。小武从地面坐起……
```

## 使用时

1. 让对方**先发参考图，并说明这张图是什么**
2. 生成时，**第一部分永远是参考图描述**（`@image` 格式，边界直接内联）
3. 然后填写单镜头模板——画面内容直接描述画面本身，不写风格词
4. 单镜头通常只有一张参考图，不需要考虑合成图的区域对应问题
