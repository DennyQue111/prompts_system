# Shot · 单镜头视频生成

## 是什么

Shot 是**单个镜头的视频生成提示词**。与 Sequence 不同，它不需要描述全片设定，只需要把这一个镜头的画面内容、运动、节奏、情绪说清楚。

单镜头通常绑定一张关键帧参考图，提示词的核心任务是：告诉视频模型这张图上的人/物应该怎么动、镜头怎么运动、氛围怎么维持。

---

## 核心原则

1. **参考图管视觉，文字管物理+摄影机。** 风格、色调、材质、渲染方式——参考图已经锁死了。文字不描述任何风格，只描述运动、力学、光线变化、镜头行为。风格词的唯一归宿是参考图本身。
2. **运镜是灵魂。** 视频区别于静帧的本质是"怎么动"——固定、缓推、横摇、手持跟拍、升降。每一个单镜头都要明确选择。
3. **焦距影响空间感。** 35mm 的空间关系跟 85mm 完全不同——广角拉伸纵深、长焦压缩平面。焦距是独立于运镜的一级字段。
4. **动作描述靠物理，不靠形容词。** 告诉模型质量如何分布、力从哪来、材质如何响应、肢体如何恢复——不是"激烈打斗"，而是"矛击自沉髋发力，过接触点后继续延伸，需可见恢复步"。
5. **有人就写情绪。** 画面中能看清人物时，加情绪关键词帮助模型理解表演调性；无人省略整行。
6. **光影变化单独写。** 光线从头到尾不变就写"持续不变"；有变化就描述。
7. **参考图说清用途就不再重复。** 前面写清楚图管什么后，画面内容直接描述画面本身。

---

## 输入结构

参考图描述块，用 `@image` 格式。每张图一行说清：是什么 + 管什么 + 不管什么。

```
## 参考图

@image [文件名.扩展名] — [名称]关键帧——[管什么]。仅用于[边界范围]，不用于[边界外]。
```

**单镜头通常只有一张关键帧参考图**，描述简洁明确即可。

## 镜头模板

```markdown
### {shot_id} · {中文简述} · {时长范围}

- **画面内容**：[画面里有什么——谁、在哪、在做什么。纯物理描述，不写风格词，不写「基于 Image X」]
- **焦距**：[具体焦距 mm，如 35mm / 50mm / 85mm；或焦段如 24–35mm。写变化路径如有变焦]
- **运镜**：[固定 / 缓推 / 横摇 / 手持跟拍 / 升降 / 拉远 / 环绕 / 甩镜 / 变焦推；可组合如"低位手持跟拍 + 短后拉"]
- **动作**：[镜头内发生了什么事——物理描述，含质量感、力的来源与传递、材质响应、肢体恢复。武戏/动作戏按五段弧写]
- **视觉母题**：[（可选）一句抽象视觉锚点，如"暗色矛线切分画面"。动作戏建议写，静态镜头可省略整行]
- **情绪**：[有人物时写调性关键词，如"温柔克制"、"压抑恐惧"；无人省略整行]
- **光影变化**：[从头到尾不变 → "持续不变"；有变化 → 具体描述变化内容和时机]
- **衔接**：[切 / 叠化 / 淡入淡出 / 闪白 / 如果是独立测试镜头省略整行]
- **负面约束**：[（可选）本镜需要规避的错误，如"禁止镜头乱晃"、"禁止出现第二个人"]
```

### 字段约束

| 字段 | 必填 | 写法 |
|------|------|------|
| **画面内容** | ✅ | 纯物理描述，禁止风格词（anime、cel shaded、illustration 等） |
| **焦距** | ✅ | 具体 mm 数或有意义的焦段范围 |
| **运镜** | ✅ | 从选项列表中选，可组合 |
| **动作** | ✅ | 物理描述 + 节奏词；武戏/动作戏按五段弧写 |
| **视觉母题** | 看情况 | 动作戏建议写；静态镜头省略整行 |
| **情绪** | 看情况 | 有人物就写，无人省略整行 |
| **光影变化** | ✅ | "持续不变" 或具体写 |
| **衔接** | 看情况 | 独立测试镜头省略整行 |
| **负面约束** | 看情况 | 有需要规避的点就写，没有省略整行 |

### 动作描述：五段弧（武戏/动作戏专用）

**仅当镜头涉及打斗、格斗、剧烈肢体动作时使用。** 文戏/静态镜头沿用自由描述。

按真实动作逻辑描述五段：**预备 → 发力 → 峰值 → 回收 → 恢复**。

每个阶段加入物理细节：质量如何转移、哪个关节驱动、材质如何响应、惯量如何处理。

```
动作：她身体下潜闪避——重心压到前脚掌，髋部带动肩膀转出，脚掌碾碎湿落叶（预备→发力），
拳套短暂逼近镜头形成压迫感，拳风带起松散毛发（峰值），
拳打出后防守手立即回位，前臂微颤显示力量残留（回收），
快速起身+横移两步回到 guard stance，胸廓随呼吸起伏（恢复）。
整体爆发力强，节奏由缓到急再回收。
```

> 五段弧的核心是"动作有始有终"——打完要收、发力后要恢复。不要让动作悬浮在半空或无缝无限循环。物理细节（质量感、材质响应、力量传递路径）比形容词更能让模型理解运动。

### 焦距选项

焦距直接影响空间压缩感和画面张力。选择时考虑：

```
24mm–35mm → 广角：拉伸纵深，适合动作跟拍、空间展示、环境沉浸
50mm → 标准：接近人眼，适合对话、中性观察
85mm+ → 长焦：压缩空间，适合特写、极端情绪、攻击性逼近
变焦 → 如 50mm→35mm：镜头内焦距变化，伴随空间感转变
```

### 运镜选项

```
固定 → 机位不动，画面静止
缓推 → 画面缓慢向前推进，增强沉浸感
横摇 → 水平方向旋转，展示环境或跟随移动
手持跟拍 → 模拟手持摄影机，轻微抖动，纪实感
升降 → 垂直方向移动，改变视角高度
拉远 → 画面向后拉，从主体退到更大场景
环绕 → 围绕主体旋转，展示空间关系
甩镜 → 快速从一个主体甩到另一个
变焦推 → 焦段变化而非机位移动，压缩空间感
```

### 衔接选项

```
切 → 硬切，最常用
叠化 → 两镜重叠渐隐，过渡自然或暗示时间流逝
淡入淡出 → 黑场过渡，段落感强
闪白 → 强光瞬间覆盖画面，冲击/记忆/转换
省略整行 → 独立测试镜头或最后一个镜头不写衔接
```

## 风格与氛围的写法

**i2v 模式下不写风格。** 参考图已经携带全部视觉风格信息（色调、材质、渲染方式）。文字中写风格词只会造成图文冲突。

如果本镜头需要明确的氛围锚定或光影基调，**在画面内容中用纯视觉事实交代**（色温、光比、可见元素），不使用风格标签。

```
画面内容：暖赭石地面 vs 冷蓝天空的高对比色调。小武从地面坐起……
```

---

## 使用时

1. 让对方**先发参考图，并说明这张图是什么**
2. 生成时，**第一部分永远是参考图描述**（`@image` 格式，边界直接内联）
3. 然后填写单镜头模板——画面内容直接描述画面本身，不写风格词
4. 单镜头通常只有一张参考图，不需要考虑合成图的区域对应问题
