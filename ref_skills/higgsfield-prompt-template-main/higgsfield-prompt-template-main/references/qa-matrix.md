## 1. 必检结构

| 检查项 | 最低合格证据 |
|---|---|
| 输出合同 | 时长/模式/画幅中至少有适用字段 |
| 参考权限 | 每个关键资产说明控制范围 |
| 身份连续 | 人物永久身份与临时状态分开 |
| 空间连续 | 人物方向、入口/远端或画面左右可追踪 |
| 道具连续 | 所有者、接触点、状态变化可追踪 |
| 镜头职责 | 每镜存在单一主要视觉问题 |
| 动作因果 | 触发、反应、结束状态完整 |
| 正向锁 | 关键要求存在唯一正确状态 |
| 最终帧 | 构图、姿态、道具、焦点和承接清楚 |
| 音频 | 可见原因与声音同步；对白归属明确 |

## 2. 冲突矩阵

| 冲突 | 修复 |
|---|---|
| `heavy handheld` + `no jitter` | 改为允许 organic handheld，禁止 digital jitter/flicker/warping |
| 全局强手持 + 局部锁机 | 局部写 `SHOT EXCEPTION / OVERRIDE` |
| `No floating props` + 悬浮板/魔法物体 | 改为 `No unintended floating props; only X floats` |
| `Every person moving from frame one` + 静止观察/空镜 | 改成呼吸与微动作，或删除全员运动规则 |
| 全程背景虚化 + 人物离画 | 锁定原焦平面，禁止 autofocus/rack focus |
| 头肩特写 + 必须看到手/脚/飞板 | 扩大景别或承认其为画外继承状态 |
| 每面尖刺 + 裸手支撑 | 增加无尖刺安全接触区 |
| 自然光 only + 无动机补光 | 删除补光，或把可见灯具声明为 practical |
| `artificial lightning` | 若意图是人工灯光，改为 `artificial lighting` |
| `pixel-for-pixel` 生成要求 | 降为参考一致；完全一致改用插片/后期 |
| 24fps + 60fps 同时出现 | 选择唯一交付帧率；慢动作另写采集/播放关系 |
| IMAX + 2.39:1 未说明 | 明确交付画幅，不把二者同时当物理规格 |
| 参考图旧造型 + 当前文字新造型 | 声明当前文字 override，列出禁止混入的旧特征 |
| `no music` + BGM/score | 保留一个音频政策 |
| Block/Shot 编号越界 | 统一声明数量、实际编号和跨段引用 |

## 3. 容量检查

出现以下三项中的两项即标记 `REWRITE_REQUIRED`：

- 单镜同时包含两个以上主要空间动作。
- 单镜包含两次以上独立情绪翻转。
- 同一镜头叠加多个主要相机运动。
- 短时长内存在长对白、剧烈动作、复杂变形和多人反应。
- 一个生成单元跨越多个地点或时间跳跃。
- 结束状态没有稳定姿态，下一段无法继承。

脚本只能用长度和关键词标记疑似超载；最终由 Codex结合剧情语义确认。

## 4. 证据等级

```text
E1 脚本检测到的明确字段/冲突
E2 原文中的可定位句子
E3 参考资产或连续性圣经
E4 Codex语义判断
E5 生成后抽帧/视频QA
```

编译前最高只能证明到 E4；不要声称已经验证生成画面。

## 5. 修复优先级

```text
P0 身份/参考权限/核心剧情冲突
P1 时长容量/物理/空间/连续性冲突
P2 镜头可见性/表演/焦点/音频冲突
P3 风格冗余、导演名、画质修辞
```

只修 affected blocks。P3 不得覆盖 P0–P2 的明确要求。
