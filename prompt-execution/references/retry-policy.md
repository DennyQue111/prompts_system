# 失败重试策略

## 默认规则

先判断失败类型，再决定重试方式：

1. **系统性失败**（ComfyUI 掉线、超时、连接断开、端口不通）：不改提示词，原样立即重试一次。
2. **内容拒生成**（模型因内容政策拒绝、返回空结果或安全拦截）：**不要原样重试**，先修改提示词——把触发拦截的具象元素换成更间接的表达（暗示代替直给、局部代替整体、氛围代替实体），再提交。
3. **内容跑偏**（多出人物、抽象概念被实体化、构图错误）：修提示词后重试一次。
4. **第二次仍失败**：标记 `blocked(原因)` 并记入状态表，继续下一个不依赖它的镜头。
5. **本轮结束后**：统一回补 blocked 镜头。回补仍失败的，向用户报告并给出选项：改提示词 / 换工作流 / 人工介入。

## 禁止行为

- 禁止失败后无记录直接跳到下一镜。WWHD 制作中 A02-004、A02-008 的 frame 因此缺失，后续回补成本更高。
- 禁止对同一镜头无限重试；两次不过就转 blocked。
- 系统性故障（服务掉线、渲染后端不连通）未排除前，不提交新的生成任务。
- 禁止为了赶进度把未通过质检的关键帧直接喂给视频环节。
